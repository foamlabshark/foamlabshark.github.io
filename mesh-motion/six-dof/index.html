sixDoFRigidBodyMotion · 六自由度

正在打开最新内容…

利用流体作用力与力矩积分刚体运动，可增加约束及弹簧等限制。

简要介绍

六自由度刚体模型由流体力和力矩计算物体的平移与转动。质量、惯量及外力决定运动响应，积分器负责推进位置和姿态。

配置时先确定受力表面、质心和惯量，再设置约束与 restraints 中的弹簧等作用。下面用带弹簧浮体说明各子字典的物理含义和相互关系。

六自由度运动由合力与合力矩驱动。平动与转动的基本关系为：

mx¨c=F,dLdt=Mm\ddot{\mathbf x}_c=\mathbf F,\qquad\frac{{\rm d}\mathbf L}{{\rm d}t}=\mathbf Mmx¨c​=F,dtdL​=M

xc 是质心位置，L 为角动量；刚体惯量、姿态与角速度共同决定 L。mass、centreOfMass 和 momentOfInertia 必须对应同一物体；constraints 限制允许运动的自由度，restraints 增加弹簧、阻尼等力。流体压力、黏性力及外部载荷共同进入运动计算。

设置位置与参数

算例问题：background

水槽内的浮体通过弹簧与固定点相连，流体作用力和弹簧力共同决定浮体运动。水和空气采用界面捕捉方法，浮体附近的运动网格与背景网格通过重叠区域交换信息。算例用于研究浮体位移、自由液面变化及弹簧恢复力，配置时需同时考虑浮体质量、转动惯量、运动约束和网格连接。

算例出处：OpenCFD OpenFOAM v2512 官方教程 multiphase/overInterDyMFoam/floatingBodyWithSpring/background。

本页重点配置：multiphase/overInterDyMFoam/floatingBodyWithSpring/background/constant/dynamicMeshDict。下表说明各条目的作用。完整算例的网格、初始场和配套模型见后文。

条目含义与设置
patches用于积分流体力的物体表面。
mass / momentOfInertia刚体质量与主惯性矩。
centreOfMass初始质心。
constraints / restraints几何约束与外加恢复力，例如运动轴限制和弹簧。

官方配置示例

constant/dynamicMeshDict

动网格类型与运动、细化参数。

配置出处：OpenCFD OpenFOAM v2512 官方教程 multiphase/overInterDyMFoam/floatingBodyWithSpring/background/constant/dynamicMeshDict（原文件）。

foam106 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      dynamicMeshDict;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

dynamicFvMesh   dynamicOversetFvMesh;

solvers
{
     VF
     {
        motionSolverLibs (fvMotionSolvers);

        motionSolver            solidBody;
        solidBodyMotionFunction drivenLinearMotion;

        cellSet                 c0;
        cOfGdisplacement        CofG;
    }

    cube
    {
        motionSolverLibs   (sixDoFRigidBodyMotion);
        motionSolver        sixDoFRigidBodyMotion;

        cellSet         c1;

        patches         (floatingObject);
        innerDistance   1000.0;
        outerDistance   1001.0;

        centreOfMass        (0.5 0.5 0.4);
        cOfGdisplacement    CofG;

        // Cuboid dimensions
        Lx              0.24;
        Ly              0.24;
        Lz              0.4;

        // Density of the solid
        rhoSolid        500;

        // Cuboid mass
        mass            #eval{ $rhoSolid*$Lx*$Ly*$Lz };

        // Cuboid moment of inertia about the centre of mass
        momentOfInertia #codeStream
        {
            codeInclude
            #{
                #include "diagTensor.H"
            #};

            code
            #{
                scalar sqrLx = sqr($Lx);
                scalar sqrLy = sqr($Ly);
                scalar sqrLz = sqr($Lz);
                os  <<
                    $mass
                *diagTensor(sqrLy + sqrLz, sqrLx + sqrLz, sqrLx + sqrLy)/12.0;
            #};
        };

        report          on;
        accelerationRelaxation 0.6;
        accelerationDamping    1;

        solver
        {
            type Newmark;
        }

        constraints
        {

            fixedAxis
            {
                sixDoFRigidBodyMotionConstraint plane;
                normal (0 0 1);
            }
        }

        restraints
        {

            linearSpring
            {
                sixDoFRigidBodyMotionRestraint linearSpring;
                anchor            (0 0.5 0.4);
                refAttachmentPt   (0.5 0.5 0.4);
                stiffness         300;
                damping           0;
                restLength        0;
            }

        }
    }
}


// ************************************************************************* //

本例由背景网格和随浮体运动的局部网格组成。dynamicOversetFvMesh负责网格更新与重叠关系；solvers内的两个子字典分别规定两组单元怎样运动。

VF作用于c0，采用solidBody中的drivenLinearMotion；该运动读取名为CofG的位移信息确定的位移。cube作用于c1，通过sixDoFRigidBodyMotion计算浮体运动，并以同名CofG记录运动中心位移。本例的初始运动中心与质心一致，两个运动设置通过该位移信息耦合。

patches (floatingObject)指定参与流体力与力矩积分的物体表面。innerDistance和outerDistance控制网格从随物体运动到不随物体运动的过渡距离；本例采用较大的过渡距离，使局部网格随浮体整体运动。

长方体尺寸为 0.24 m × 0.24 m × 0.4 m，体积为 0.02304 m³。密度为 500 kg/m³，因此mass中的表达式得到质量 11.52 kg。momentOfInertia按均匀长方体公式计算，三个主惯性矩依次为 0.208896、0.208896 和 0.110592 kg·m²。修改尺寸或密度时，这两段表达式会重新计算质量和惯量。

Newmark用于积分刚体运动。accelerationRelaxation 0.6对加速度更新作松弛处理；accelerationDamping 1不再额外缩小加速度。二者影响运动更新，与弹簧的物理阻尼分别配置。

约束子字典虽然命名为fixedAxis，实际类型却是plane。法向量为(0 0 1)，限制的是沿 z 方向的平移，使平移保持在水平面内；该设置没有指定绕哪根轴转动。

弹簧固定端位于(0 0.5 0.4)，物体连接点初始位于(0.5 0.5 0.4)，两点相距 0.5 m。刚度 300 N/m、原长 0 m，对应初始拉力大小 150 N，方向指向固定端。damping 0表示弹簧模型不提供阻尼；流体仍可能耗散运动能量。

熊猫说：子字典名称只用于组织配置，真正决定约束的是类型字段。这里的 fixedAxis 不能解释为“固定转轴”。另外，restLength 为零意味着初始时刻已经存在弹簧拉力。

运行后先查看运动日志中的质心位移与姿态，再在 ParaView 中观察局部网格、浮体和水面的相对位置。还应检查重叠区域是否持续覆盖，以及两相体积和连续性误差是否出现异常变化。

0.orig/U 设置 U 的内部初值和边界条件。dimensions 为 [0 1 -1 0 0 0 0]，单位为 m/s。internalField 为 uniform (0 0 0)；uniform 表示所有内部单元采用相同初值。

  • oversetPatch 采用 overset，通过重叠网格框架更新边界场。
  • overset 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。参数为 patchType overset。
  • stationaryWalls、sidePatch、atmosphere 采用 pressureInletOutletVelocity，出流时外推速度，流入时依据通量确定法向速度。参数为 value uniform (0 0 0)。
  • floatingObject 采用 movingWallVelocity，根据网格壁面运动计算流体壁面速度。参数为 value uniform (0 0 0)。

0.orig/U还读取"caseDicts/setConstraintTypes"。以 #includeEtc 引入的配置来自安装环境；相对路径引用的文件需要随算例保留，修改引用内容会改变最终展开的字典。

  • PIMPLE/momentumPredictor = no：控制是否单独求解动量预测步骤。
  • PIMPLE/nOuterCorrectors = 1：每个时间步的外耦合迭代次数。
  • PIMPLE/nCorrectors = 3：每轮压力速度耦合中的压力校正次数。
  • PIMPLE/nNonOrthogonalCorrectors = 0：压力或扩散方程的非正交校正次数。
  • relaxationFactors/equations/".*" = 1：限制每轮迭代的更新幅度；越接近 1，松弛越弱。
