前言｜Bob Robey 的并行计算经历

PDF p.23

I could not have foreseen where this journey into parallel computing would take us. “Us” because the journey has been shared by numerous colleagues over the years.

我当初无从预见，并行计算这段旅程会把我们带往何方。我说“我们”，是因为这些年一直有许多同事相伴。

从激波管实验到计算中心

20 世纪 90 年代初，Bob 在新墨西哥大学为激波管实验编写可压缩流体程序，寻找能运行大规模模拟的机器。随后他和同事参与筹建 Maui 高性能计算中心，中心于 1993 年成立。他负责授课并指导研究生开展并行计算。

标准如何进入实际程序

Bob 回忆过 MPI 发布前对其复杂度的担忧，也回忆了成熟实现对采用率的影响。Argonne 的消息传递移植工作转向 MPICH，使程序开发者能够立即利用标准接口。第 8 章的通信例程便建立在这类可用实现之上。

一项求和实验与一场山火

2010 年，他和儿子 Jon 在流体程序中尝试补偿求和，观察到质量守恒误差改善。2011 年的 GPU 暑期项目需要为自适应网格查找邻居。Las Conchas 山火疏散期间，David Nicholaeff 提议用哈希替换难以移植的 k-d 树。这个选择促成了 CLAMR 的 GPU 实现，也成为第 5 章算法实例的来源。

长期的教学项目

2016 年，Bob、Hai Ah Nam 与 Gabe Rockefeller 在洛斯阿拉莫斯国家实验室共同创办暑期并行计算研究实习。十周安排先上课，再在研究人员指导下做项目，把并行算法、真实机器与可验证的科研问题放在一起。

前言｜Yulie Zamora 的并行计算经历

From my experiences, I realized how valuable personal interactions are to learning how to write parallel code. I also was frustrated by the lack of a textbook or reference that discusses the current hardware.

从安装节点开始

Yulie 在康奈尔接到的第一个任务是为集群安装 Knights Corner 处理器。从搬动服务器、设置 BIOS，到跨节点优化应用，这段过程让她接触到完整的计算系统。之后她参加首届 LANL 暑期项目，研究 OpenMP 性能，并在技术会议上报告成果。

从移植项目到写书

一次 GPU hackathon 中，团队在一周内将程序迁移至 OpenACC，作者回忆该算例获得约 60 倍加速。随后她进入芝加哥大学，在 Ian Foster 与 Henry Hoffmann 指导下学习研究。为新生授课和担任高级分布式系统课程助教，使她练习面向不同基础的读者解释同一技术。

关于本书｜读者与学习目标

PDF p.30

One of the most important tasks for an explorer is to draw a map for those who follow.

探路者最重要的工作之一，是为后来者画一张地图。

适合哪些读者

面向高年级本科并行计算课程、计算专业人员，以及关心运行时间、规模和能耗的开发者。作者从并行基础讲起，希望读者已具备一般编程能力，最好熟悉 C、C++ 或 Fortran，并能处理操作系统、网络和软件安装的基本问题。

四条贯穿全书的经验

把程序运行所耗时间纳入设计；计算数据占用与重复加载次数；尽量使用同一缓存行中相邻的值；并行化前后持续做正确性检查。原书以 64 字节缓存行为例，一次加载可带来相邻的 8 个 double 或 16 个 float。硬件取值随架构变化，练习重点是从实际粒度算出有效利用了多少数据。

本书结构与课程路线

PDF p.32

The order of topics is oriented towards someone tackling a high performance computing project.

本书安排各主题的顺序，着眼于实际着手开展高性能计算项目的人。

按工程过程阅读

第一部分（1–5）从性能目标进入测量、数据设计和算法；第二部分（6–8）讲 CPU 的向量、线程与 MPI；第三部分（9–13）讲 GPU 架构、代码与剖析；第四部分（14–17）处理亲和性、调度、文件与开发工具。读者可以在遇到硬件名词时查术语表，或查看附录 C 末尾实物照片。

按课程重点阅读

作者给出的入门路线依次选第 1、3 章，4.1–4.2，第 7、8 章，14.1–14.5，第 9、10 章及 11.1–11.2。课程也可以加入并行算法、向量化或并行 I/O。原书认为全部材料足以安排至少两个学期。

第 4 章｜数组布局与模型

第 1 题 · 连续分配下三角矩阵

原答采用方阵边长 n 和作者的几何方向约定。按行长 n,n−1,…,1 排列共有 n(n+1)/2 个元素；第 j 行的起点为 jn−j(j−1)/2。单次分配时检查大小乘积、零规模、分配状态以及行指针区之后的元素对齐。

第 2 题 · 让 C 访问获得 Fortran 列优先顺序

原答把 Fortran 的 x(j,i) 对应到 C 的 x[i−1][j−1]，第一下标 j 变化最快。一维缓冲中偏移为 (i−1)*jmax+(j−1)。传给 Fortran 或 I/O 例程时要使用实际元素缓冲；指针表和连续 double 存储有不同布局。

第 3 题 · 写出 RGB 的 AoSoA 索引

原答按向量宽度分块，每块分别保存 R、G、B 的连续通道。本题采用零基索引，块号 i/VV，通道 i%VV。原书宏中的“#define VV = 4”和“%4-1”有误，后者在 i 为 4 的倍数时产生负下标。i=50、VV=4 对应第 12 块第 2 通道。

C · i 为无副作用的非负索引。实际接口也可用内联函数避免宏参数重复求值。
#define VV 4
#define COLOR(i, field) (pixels[(i)/VV].field[(i)%VV])

第 8 章｜MPI 通信

原书 p.629 / PDF p.665

Even with the vector version of the ghost cell exchange, we have to be careful that we do not modify the buffers that are still in the process of being sent.

即便使用向量派生类型交换幽灵单元，也要避免修改仍在发送过程中的缓冲区。

第 1 题 · 打包或手填缓冲交换时能否只等接收

原答指出非阻塞发送返回时，MPI 仍可能读取临时缓冲区。仅等接收完成就释放、覆盖打包数组，可能破坏发送内容。复用或释放前须通过发送请求等机制确认完成。

第 2 题 · 用派生向量类型时只阻塞接收有什么收益和条件

原答指出发送直接引用原数组，可推迟对发送的等待，与独立计算重叠。数组仍然存活并不等于可以修改；所有仍被发送引用的单元都要保持有效且不被覆盖。

第 3 题 · 把 waitall 改为阻塞接收是否总能工作

原答说明就算不交换角点也可能在发送未完成前写回原数组。先核对所有发送已经匹配，再在覆盖相应数组前等待发送完成。不同消息大小和时序均须测试，不能从少数小消息成功推出协议安全。

第 4 题 · 用 MPI_ANY_TAG 替换显式标签

流式多处理器（SM） Streaming multiprocessor (SM)

Usually used to describe the multiprocessors of a GPU that are designed for streaming operations. These are tightly-coupled, symmetric processors (SMP) that have a single instruction stream operating on multiple threads.

流式存储 Streaming store

针对预期很少复用的连续写入，采用非临时等方式减少缓存污染或读占有开销；是否绕过某一层缓存取决于架构。

英文原释义

A store of a value directly to main memory, bypassing the cache hierarchy.

原书 p.652

数组步长 Stride (arrays)

相邻逻辑元素在存储地址上的间隔。C 行主序二维数组中相邻列通常相差一个元素，相邻行相差实际行跨度。

英文原释义

Distance between indexed elements in an array. In C, in the x dimension, the data is contiguous or a stride of 1. In the y dimension, the data has a stride of the length of the row.

原书 p.652

超线性加速 Super-linear speedup

相对于给定串行基线，p 个资源得到超过 p 的加速；分块后工作集进入更快缓存层是可能原因。

英文原释义

Performance that is better than the ideal strong scaling curve. This can happen because the smaller array sizes fit into a higher level of cache, resulting in better cache performance.

原书 p.652

对称多处理（SMP） Symmetric processors (SMP)

多个处理器作为对等参与者访问共同的系统资源和共享内存。原书将其描述为 SIMT 锁步执行，二者语义不同。

英文原释义

All cores of the multicore processor operate in unison in a single-instruction, multiple-thread (SIMT) fashion.

Work that is divided into separate pieces and parceled out to individual processes or threads.

任务并行 Task parallel

英文原释义

A form of parallelism where processors or threads work on separate tasks.

原书 p.652

时间局部性 Temporal locality

英文原释义

Recently referenced data that is likely to be referenced in the near future.

测试驱动开发（TDD） Test-driven development (TDD)

先为预期行为编写可失败的测试，再实现功能并重构，持续反馈设计和正确性。

英文原释义

A process of code development where the tests are created first.

测试套件 Test suite

一组面向功能、边界或回归风险的测试。通过表示已覆盖用例符合期望。

英文原释义

A set of problems that exercise parts of an application to guarantee that parts of the code are still working.

A separate instruction pathway through a process created by having more than one instruction pointer.

多重循环的各层控制语句或结尾之间没有额外代码，便于某些结构化循环变换。

英文原释义

Two or more loops that have no extra statements between the for or do statements or the end of the loops.

原书 p.653

时间复杂度 Time complexity

在指定模型下，执行时间或基本步骤数随输入规模增长的规律。实际性能还受访存、缓存和常数因子影响。

英文原释义

Time complexity takes into account the actual cost of an operation on a typical modern computing system. The largest adjustment for time is to consider the cost of memory loads and caching of data.

原书 p.653

地址转换后备缓冲器（TLB） Translation lookaside buffer (TLB)

缓存虚拟页到物理页等地址翻译信息。TLB 未命中可能需要页表遍历，和缺页导致页面调入是不同事件。

英文原释义

The table of entries to translate virtual memory addresses to physical memory. The limited size of the table means that only recently used page locations are held in memory, and a TLB miss occurs if it is not present, incurring a significant performance hit.

原书 p.653

统一内存 Unified memory

给 CPU 和 GPU 提供统一的指针或受管理存储视图，数据可能共享物理内存或按需迁移。访问仍受同步和平台能力约束。

英文原释义

Memory that has the appearance of being a single address space for both the CPU and the GPU.

单独验证程序的一个函数、类或组件在给定输入下满足约定。

英文原释义

Testing of each individual component of a program.

原书 p.653

未初始化内存 Uninitialized memory

变量的有效值尚未建立就被读取。应在首次使用前按语言规则显式初始化所需数据。

英文原释义

Memory that is used before its values are set.

用户空间 User space

普通应用运行的受限执行环境，通过系统调用访问内核服务；操作系统仍负责保护、调度和资源管理。

英文原释义

The scope of control of operations for a program such that it is isolated from the purview of the operating system.

与实验或现实观测在规定误差范围内一致的结果。物理模型验证与检查代码是否正确实现方程可分别评估。

Results of a calculation that are compared favorably to experimental or real-world data.

A pathway through a vector operation on vector registers for a single data element much like a lane on a multi-lane freeway.

英文原释义

The number of operations done in a single cycle by a vector unit.

一条向量指令或高层向量表达式对多个元素施加同类计算。

An operation on two or more elements of an array with a single operation or instruction being supplied to the processor.

向量位宽 Vector width

向量寄存器或操作覆盖的总位数，通常以 bit 表示。

英文原释义

The width of the vector unit, usually expressed in bits.

The process of grouping operations together so more than one can be done at a time.

A database that tracks the changes to your source code, simplifies the merging of multiple developers, and provides a way to roll back changes.

When a cache has data to be operated on in the cache from a previous operation as the current operation begins.

An alternate term for a thread workgroup.

A group of threads operating together with a single instruction queue.
