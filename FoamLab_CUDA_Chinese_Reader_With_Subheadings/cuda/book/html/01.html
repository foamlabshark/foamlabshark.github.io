第 1 章 使用 GPU 的优势

本章所加的小标题用于网页阅读辅助，原书第 1 章并未为这些段落单独编号。

GPU 与 CPU 的性能差异

图形处理器（GPU）在相近的价格和功耗范围内，通常能提供比中央处理器（CPU）更高的指令吞吐量和内存带宽。许多应用可以利用这些能力，使程序在 GPU 上比在 CPU 上运行得更快（参见"GPU 应用"）。现场可编程门阵列（FPGA）等其他计算设备同样具有较高的能效，但与 GPU 相比，其编程灵活性要低得多。

CPU 和 GPU 的设计目标

GPU 与 CPU 的能力差异源于两者的设计目标不同。CPU 的设计重点是尽可能快地执行一串操作，这串操作称为一个线程；CPU 可以并行执行的这类线程通常只有几十个。GPU 则擅长同时执行数千个线程，通过大规模并行获得更高的总体吞吐量，即使单个线程的执行速度相对较慢也能实现这一点。

GPU 面向高度并行的计算任务，因此其芯片设计会将更多晶体管用于数据处理，而不是数据缓存和流程控制。图 1 展示了 CPU 与 GPU 在芯片资源分配方面的一个示例。

通过并行计算隐藏内存延迟

把更多晶体管用于数据处理（例如浮点计算）有利于执行高度并行的任务。GPU 可以通过计算来掩蔽内存访问延迟，而不必像 CPU 那样主要依赖大型数据缓存和复杂的流程控制来规避较长的内存访问延迟；后两者都会消耗大量晶体管资源。

CPU 与 GPU 的协同

一般而言，一个应用既包含可并行执行的部分，也包含必须顺序执行的部分。因此，系统通常会同时使用 GPU 和 CPU，以尽可能提高整体性能。并行度较高的应用能够利用 GPU 的大规模并行特性，相较于仅在 CPU 上执行获得更高性能。

术语说明： GPU（图形处理器）中的"图形"一词源于其早期用途。GPU 最初是约二十年前为加速图形渲染而设计的专用处理器；在实时、高清和三维图形需求的推动下，它逐渐发展为能够承担远超图形渲染任务的通用处理器。
