第 3 章 可扩展的编程模型

下列小标题为便于阅读而增加，不代表原书新增编号。

多核与众核计算带来的编程挑战

随着多核 CPU 和众核 GPU 的出现，主流处理器芯片已经成为并行系统。软件开发面临的挑战，是让应用程序能够以透明、可扩展的方式利用不断增加的处理器核心数量。这与三维图形应用能够适应核心数量差异很大的众核 GPU、并相应扩展并行度的思路类似。

CUDA 并行编程模型旨在解决这一问题，同时让熟悉 C 等标准编程语言的开发者能够以较低的学习成本上手。

三个核心抽象：线程组、共享内存、屏障同步

该模型的核心包含三个抽象概念：线程组层次结构、共享内存和屏障同步。这些概念通过少量语言扩展提供给程序员。它们使细粒度的数据并行和线程并行能够嵌套在粗粒度的数据并行与任务并行之中。

从子问题划分到线程块调度

这些抽象引导程序员先把问题划分为较大的子问题，再由多个线程块并行、独立地处理这些子问题；随后，每个线程块中的所有线程可以协同工作，将子问题继续拆分为更细的计算任务。

这种分解方式既保留了语言表达能力------线程可以在解决子问题时相互协作------也实现了自动可扩展性。GPU 可以按照任意顺序调度各线程块；不同线程块既可以并发执行，也可以依次执行。只要编译后的 CUDA 程序遵循该模型，它就能在具有不同数量多处理器的 GPU 上运行，实际的多处理器数量由运行时系统处理。

并行模型的可扩展性

这种可扩展的编程模型使 GPU 架构能够覆盖广泛的产品范围。厂商可以通过调整多处理器数量和内存分区数量来扩展架构，从高性能的 GeForce GPU，到面向专业计算的 Quadro 和 Tesla 产品，再到不同档次的主流 GeForce GPU。
