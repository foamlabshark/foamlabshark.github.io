liquidFilmFoam

正在打开最新内容…

用有限面积方法计算表面上的薄液膜流动。

简要介绍

薄液膜的厚度远小于沿壁面方向的尺度，可以沿厚度积分流动方程，把三维液层简化为曲面上的膜厚和平均速度。没有质量源时，液膜连续性为：

∂tδ+∇s⋅(δUs)=0\partial_t\delta+\nabla_s\cdot(\delta\mathbf U_s)=0∂t​δ+∇s​⋅(δUs​)=0

δ 为膜厚，Us\mathbf U_sUs​ 为厚度平均切向速度。膜厚随流入、流出改变，重力、黏性和表面张力通过膜动量方程影响沿表面的运动。该描述适合不可压缩 Newtonian 液体的层流薄膜，厚度方向采用薄膜近似。

liquidFilmFoam 用有限面积方法推进层流薄液膜的膜厚与表面速度，考虑重力、黏性和表面张力。适用前提是膜厚相对于表面变化尺度足够小。

1. 了解算例问题

算例问题：cylinder

薄液膜沿固体表面流动，其厚度远小于沿面尺度，因此在表面网格上描述流动。算例用于设置沿面的重力、流量及黏性作用，主要观察膜厚和沿面速度。

算例出处：OpenCFD OpenFOAM v2512 官方教程 finiteArea/liquidFilmFoam/cylinder。

2. 运行与准备

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/finiteArea/liquidFilmFoam/cylinder" "$FOAM_RUN/cylinder-reference"
cd "$FOAM_RUN/cylinder-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

3. 修改配置

文件先修改什么
constant/transportProperties流体输运物性。改变材料时，在此修改黏度、密度或扩散率；各字段的量纲需保持一致。
0.orig/finite-area/Us本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
0.orig/finite-area/h热力学求解器中的比焓，J/kg；浅水求解器中同名 h 则表示水深，须按量纲区分。
0.orig/finite-area/manningField本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
constant/g重力加速度向量，m/s²；方向按全局坐标填写。
system/decomposeParDict并行分区数量和方法；运行进程数应与 numberOfSubdomains 一致。
system/finite-area/faMeshDefinition从体网格的面构造有限面积网格，并定义其边界边。

本例时间格式为 none，时间步与该格式共同决定非定常过程的时间分辨率。

system/controlDict 设置为：结束时刻 endTime 0.5；初始时间步 deltaT 0.0002；输出依据 writeControl timeStep；输出间隔 writeInterval 100。非定常计算中还应结合 Courant 数检查时间步。

表中列出本例首先需要检查的文件。其余字段、数值字典和完整解读见下方“完整配置与逐项解读”。

4. 检查计算结果

在生成的表面网格上查看液膜厚度或表面浓度，并按表面面积积分检查总量随时间的变化。

按 controlDict 的写出设置打开结果目录。若 functions 或 Allrun 配置了采样、积分或统计，继续查看 postProcessing 及相应日志；没有启用的后处理不会自动产生。

初始场与边界条件

下表列出本算例提供的初始字段。带 0.orig 的路径是初始化模板，Allrun 通常先将其恢复为 0；若脚本随后执行 setFields，实际初始分布以初始化后的文件为准。

文件设置内容
0.orig/finite-area/Us本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
0.orig/finite-area/h热力学求解器中的比焓，J/kg；浅水求解器中同名 h 则表示水深，须按量纲区分。
0.orig/finite-area/manningField本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
0.orig/finite-area/Us：初始场及其边界条件；量纲见 dimensions，场名见 object。

0.orig/finite-area/Us

配置出处：OpenCFD OpenFOAM v2512 官方教程 finiteArea/liquidFilmFoam/cylinder/0.orig/finite-area/Us（原文件）。

boundaryField
{
    #includeEtc "caseDicts/setConstraintTypes"

    inlet
    {
        type        zeroGradient;

    outlet

        type        zeroGradient;
    }

    side
    {

    }

    symmetry

    }

0.orig/finite-area/Us 设置 Us 的内部初值和边界条件。dimensions 为 [0 1 -1 0 0 0 0]，单位为 m/s。internalField 为 uniform (0 0 0)；uniform 表示所有内部单元采用相同初值。

  • inlet、outlet 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。
  • side、cylinder 采用 slip，法向速度为零，切向速度由内部场外推。
  • symmetry 采用 symmetry，按局部面法向施加对称约束。

0.orig/finite-area/Us还读取"caseDicts/setConstraintTypes"。以 #includeEtc 引入的配置来自安装环境；相对路径引用的文件需要随算例保留，修改引用内容会改变最终展开的字典。

system/finite-area/faSolution：本算例的配套配置，字段和参数见文件正文。

system/finite-area/faSolution

配置出处：OpenCFD OpenFOAM v2512 官方教程 finiteArea/liquidFilmFoam/cylinder/system/finite-area/faSolution（原文件）。

FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;

}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

solvers
{
    Us
    {
        solver          PBiCGStab;
        preconditioner  DILU;
        tolerance       1e-07;
        relTol          0.01;
    }

    h
    {
        solver          PBiCGStab;
        preconditioner  DILU;
        tolerance       1e-07;
        relTol          0.01;
    }
}

solution
{
    iterations 15;
}

relaxationFactors
{
    h   0.5;
    Us  0.5;
}

cache
{
    grad(h);
    grad(Us);
}


// ************************************************************************* //

system/finite-area/faSolution 中各项设置的作用如下。

  • solvers/Us/preconditioner 设为 DILU：选择线性方程的预条件方法。
  • solvers/Us/tolerance 设为 1e-07：规定该模型或算法的收敛阈值。
  • solvers/Us/relTol 设为 0.01：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
  • solvers/h/preconditioner 设为 DILU：选择线性方程的预条件方法。
  • solvers/h/tolerance 设为 1e-07：规定该模型或算法的收敛阈值。
  • solvers/h/relTol 设为 0.01：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
  • relaxationFactors/h 设为 0.5：热力学求解器中的比焓，J/kg；浅水求解器中同名 h 则表示水深，须按量纲区分。
  • relaxationFactors/Us 设为 0.5：本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。

    format      ascii;
    class       dictionary;
    object      controlDict;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

application     liquidFilmFoam;

startFrom       startTime;

startTime       0;

stopAt          endTime;

endTime         0.5;

deltaT          0.0002;

writeControl    timeStep;

writeInterval   100;

purgeWrite      0;

writeFormat     ascii;

writePrecision  6;

writeCompression off;

timeFormat      general;

timePrecision   6;

runTimeModifiable yes;

adjustTimeStep      no;

maxCo               5;

maxDeltaT           0.1;

functions
{
    #include "FOsurfaceCourantNumber"
}

// ************************************************************************* //

system/controlDict 中各项设置的作用如下。

  • application 设为 liquidFilmFoam：指定由 Allrun 等脚本调用的应用程序。
  • startFrom 设为 startTime：决定从给定起始时刻还是已有结果继续计算。
  • startTime 设为 0：给定起始时刻。
  • endTime 设为 0.5：规定计算结束的时间或稳态迭代终点。
  • deltaT 设为 0.0002：设置时间步；启用自动调步后它用于起步。
  • writeControl 设为 timeStep：选择按时间步、模拟时间等事件写出结果。
  • writeInterval 设为 100：给出与 writeControl 配套的写出间隔。
  • purgeWrite 设为 0：控制保留多少个结果时间目录；0 表示不自动清除。
  • runTimeModifiable 设为 yes：决定运行中是否重新读取可修改的字典。
  • adjustTimeStep 设为 no：控制是否根据 Courant 数自动调整时间步。
  • maxCo 设为 5：限制流动 Courant 数。
  • maxDeltaT 设为 0.1：限定自动时间步的上限。

system/controlDict还读取"FOsurfaceCourantNumber"。相对路径引用的文件需要随算例保留，修改引用内容会改变最终展开的字典。

瞬态计算应同时检查时间步与写出间隔：前者影响时间离散和稳定性，后者只决定保存结果的频率。仅缩小 writeInterval 不会提高计算本身的时间分辨率。

Bash / 终端16 行
#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

restore0Dir

runApplication blockMesh

runApplication makeFaMesh

runApplication setFields

runApplication $(getApplication)

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. restore0Dir 将 0.orig 恢复为求解所用的 0 目录。
  3. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格。
  4. makeFaMesh 从体网格中选取表面面片，生成有限面积网格。
  5. setFields 按几何选区或拓扑集合给已有场设置初值。
  6. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
