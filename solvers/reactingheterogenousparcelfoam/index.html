reactingHeterogenousParcelFoam

正在打开最新内容…

耦合求解连续流体与发生异相反应的颗粒。

简要介绍

高温气体中的液滴或固体颗粒会同时运动、换热并改变质量和组成。颗粒释放的挥发分或蒸气进入气相，表面反应则消耗颗粒和气体组分。把颗粒流向气相的净质量转移率记为 ṁ_p→g：

dmpdt=−m˙p→g,m˙p→g=∑im˙i,p→g\frac{{\rm d}m_p}{{\rm d}t}=-\dot m_{p\to g},\qquad\dot m_{p\to g}=\sum_i\dot m_{i,p\to g}dtdmp​​=−m˙p→g​,m˙p→g​=i∑​m˙i,p→g​

各组分转移率由相变、挥发分析出或表面反应模型确定，温度由换热和反应能量收支更新。气相方程接收相应的质量、动量和能量源。材料组成、粒径、入口气体状态和反应机理共同决定颗粒的加热、转化与消耗历程。

reactingHeterogenousParcelFoam 将多组分反应颗粒及非均相反应与载流计算耦合。适合固体表面反应等气固转化过程，材料组成与反应模型共同确定颗粒消耗及气相源。

1. 了解算例问题

算例问题：rectangularDuct

反应性颗粒随气流通过矩形管道，颗粒表面与气相组分发生非均相反应，并交换热量和质量。算例关注颗粒温度、质量及气相组分沿管道的变化。

算例出处：OpenCFD OpenFOAM v2512 官方教程 lagrangian/reactingHeterogenousParcelFoam/rectangularDuct。

2. 运行与准备

以下命令由本站依据官方算例目录整理。该目录已包含初始场和 blockMeshDict，可复制到新的工作目录，建立并检查网格后启动求解。

Bash / 终端6 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/lagrangian/reactingHeterogenousParcelFoam/rectangularDuct" "$FOAM_RUN/reactingHeterogenousParcelFoam-study"
cd "$FOAM_RUN/reactingHeterogenousParcelFoam-study"
blockMesh
checkMesh
reactingHeterogenousParcelFoam > log.reactingHeterogenousParcelFoam 2>&1

blockMesh 根据算例字典生成网格，checkMesh 检查网格质量。确认检查结果后执行最后一行；求解输出保存到 log.reactingHeterogenousParcelFoam。修改过的算例保存在副本中，再次复制时应另取目录名。

打开官方算例目录

3. 修改配置

文件先修改什么
0/U流体速度向量；修改入口速度或壁面运动时从此字段入手。
0/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。
0/p_rgh扣除重力静压贡献的压力；应与 p、rho、g 及参考高度的定义一致。
0/T温度，单位 K；入口温度、加热壁面和绝热壁面在此分别设置。
constant/reactingCloud1Properties配套模型数据或初始化设置；它由主字典引用或由 Allrun 中的预处理程序读取。
constant/thermophysicalProperties状态方程、热容、输运模型与组分物性。先确定 thermoType 组合，再填入物性系数。
constant/turbulenceProperties层流、RAS 或 LES 的选择及模型系数。切换模型后同步补齐其输运字段和数值设置。

本例时间格式为 Euler，时间步与该格式共同决定非定常过程的时间分辨率。

system/controlDict 设置为：结束时刻 endTime 25；初始时间步 deltaT 0.01；输出依据 writeControl adjustable；输出间隔 writeInterval 1。非定常计算中还应结合 Courant 数检查时间步。

system/fvSolution 的 PIMPLE 设置为 nOuterCorrectors 1、nCorrectors 2、nNonOrthogonalCorrectors 0。各校正步骤及线性方程容差的完整解读列在下方。

当前启用 kOmegaSST，需检查 k、omega 及其壁面条件。目录中保留的其他模型字段仅在切换到相应模型时使用。

表中列出本例首先需要检查的文件。其余字段、数值字典和完整解读见下方“完整配置与逐项解读”。

4. 检查计算结果

在 lagrangian 输出中观察颗粒位置、速度和模型写出的粒径、温度等属性。结合注入、逸出、沉积与域内存量核对颗粒质量；有双向耦合时比较连续相变化。

按 controlDict 的写出设置打开结果目录。若 functions 或 Allrun 配置了采样、积分或统计，继续查看 postProcessing 及相应日志；没有启用的后处理不会自动产生。

dimensions      [0 0 0 0 0 0 0];

boundaryField
{
    walls
    {
        type            zeroGradient;
    }

    outlet
    {
        type            inletOutlet;
        value           uniform 0.8;
        inletValue      uniform 0.8;
    }

    inlet
    {
        type            fixedValue;
        value           uniform 0.8;
    }
}


// ************************************************************************* //

0/N2 设置 N2 的内部初值和边界条件。dimensions 为 [0 0 0 0 0 0 0]，为无量纲量。internalField 为 uniform 0.8；uniform 表示所有内部单元采用相同初值。

  • walls 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。
  • outlet 采用 inletOutlet，出流时外推，回流时采用 inletValue。参数为 value uniform 0.8，inletValue uniform 0.8。
  • inlet 采用 fixedValue，边界始终采用给定的 value。参数为 value uniform 0.8。

system/controlDict 中各项设置的作用如下。

  • application 设为 reactingHeterogenousParcelFoam：指定由 Allrun 等脚本调用的应用程序。
  • startFrom 设为 latestTime：决定从给定起始时刻还是已有结果继续计算。
  • startTime 设为 0：给定起始时刻。
  • endTime 设为 25：规定计算结束的时间或稳态迭代终点。
  • deltaT 设为 0.01：设置时间步；启用自动调步后它用于起步。
  • writeControl 设为 adjustable：选择按时间步、模拟时间等事件写出结果。
  • writeInterval 设为 1：给出与 writeControl 配套的写出间隔。
  • purgeWrite 设为 0：控制保留多少个结果时间目录；0 表示不自动清除。
  • runTimeModifiable 设为 yes：决定运行中是否重新读取可修改的字典。
  • adjustTimeStep 设为 yes：控制是否根据 Courant 数自动调整时间步。
  • maxCo 设为 1：限制流动 Courant 数。
  • maxDeltaT 设为 0.03：限定自动时间步的上限。

查看官方原文件 · 下载此配置文件

瞬态计算应同时检查时间步与写出间隔：前者影响时间离散和稳定性，后者只决定保存结果的频率。仅缩小 writeInterval 不会提高计算本身的时间分辨率。
