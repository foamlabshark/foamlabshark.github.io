rhoReactingBuoyantFoam

正在打开最新内容…

模拟包含浮力作用的可压缩反应流。

简要介绍

反应流中，流体输运把燃料与氧化剂带到一起，化学反应改变组分并释放或吸收热量，温度和密度变化又影响流动。每个组分的质量分数满足输运与反应收支：

∂t(ρYi)+∇⋅(ρUYi)=∇⋅(ρDi∇Yi)+ω˙i,∑iYi=1\partial_t(\rho Y_i)+\nabla\cdot(\rho\mathbf UY_i)=\nabla\cdot(\rho D_i\nabla Y_i)+\dot\omega_i,\qquad\sum_iY_i=1∂t​(ρYi​)+∇⋅(ρUYi​)=∇⋅(ρDi​∇Yi​)+ω˙i​,i∑​Yi​=1

YiY_iYi​ 为组分质量分数，DiD_iDi​ 表示所采用扩散闭合的系数，ω˙i\dot\omega_iω˙i​ 为化学反应质量源，单位 kg/(m³·s)。反应机理决定各组分的生成、消耗关系；燃烧模型将反应速率与湍流混合联系起来；能量方程计算对应的热释放和温度变化。

rhoReactingBuoyantFoam 在反应流中加入重力，并使用 p_rgh 处理压力与浮力耦合，适合热释放引起的上升流及分层。热力学压力、温度和重力修正压力应描述同一初始状态。

1. 明确搭建方案

v2512 教程中没有直接以 rhoReactingBuoyantFoam 为 application 的独立算例。下面以 rhoReactingFoam 的同族配置为参考，按本程序实际读取的字段和模型说明搭建方法。

查看 rhoReactingFoam 的完整文件与运行流程

2. 设置字段与模型

关键配置示例

constant/g

foam2 行
dimensions [0 1 -2 0 0 0 0];
value (0 0 -9.81);

重力沿全局 z 轴负方向。这里的 value 是加速度向量，不能填入压力；p_rgh 的初值和边界还需使用同一重力势。

同族算例的物性配置

文件先修改什么

3. 搭建与运行

  1. 从 rhoReactingFoam 的组分输运与热化学设置开始，先使各组分名称、质量分数和反应机理一致。
  2. 加入 g，并依据初始温度和压力得到的密度设置 p_rgh。开口压力与速度条件共同约束通量，壁面可采用与指定速度通量配套的 fixedFluxPressure。
  3. 把压力求解条目配置为 p_rgh，保留末次压力校正所需的严格容差，再设置瞬态时间步与 Courant 数。
Bash / 终端1 行
rhoReactingBuoyantFoam -case ./myCase

完成网格、初始场和上述模型配置后，在 myCase 中运行本程序。此命令只启动求解，不会代替生成网格、建立区域或初始化颗粒；这些步骤应在运行前完成。

熊猫说：仅把 application 改名不会建立 p_rgh。缺少重力修正压力，或 p、T、p_rgh 对应不同初始状态，都会妨碍压力与密度的正确初始化。

4. 检查计算结果

同时观察温度、主要组分和浮力驱动流动，检查火焰或高温区的位置及燃料消耗。结合质量、元素和能量收支判断反应与流动耦合。

算例问题：groundAbsorption

含有可吸附组分的气体流经具有吸附能力的壁面，壁面吸附量随局部组分和压力变化。算例将气相输运与表面吸附动力学连接，重点检查组分衰减、壁面吸附量及质量收支。

算例出处：OpenCFD OpenFOAM v2512 官方教程 combustion/rhoReactingFoam/groundAbsorption。

constant/thermophysicalProperties

配置出处：OpenCFD OpenFOAM v2512 官方教程 combustion/rhoReactingFoam/groundAbsorption/constant/thermophysicalProperties（原文件）。

foam32 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      thermophysicalProperties;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

thermoType
{
    type            heRhoThermo;
    mixture         reactingMixture;
    transport       sutherland;
    thermo          janaf;
    energy          sensibleEnthalpy;
    equationOfState perfectGas;
    specie          specie;
}

inertSpecie N2;

fuel        CH4;

chemistryReader foamChemistryReader;

foamChemistryFile "<constant>/reactions";

foamChemistryThermoFile "<constant>/thermo.compressibleGas";


// ************************************************************************* //

constant/thermophysicalProperties中的 thermoType将不同物性关系组合成所需的热力学模型。

  • type = heRhoThermo：创建热力学对象。
  • mixture = reactingMixture：规定纯物质或组分混合方式，同时读取组分和反应机理。
  • transport = sutherland：确定黏度及导热的物性关系，黏度随温度按 Sutherland 关系变化。
  • thermo = janaf：确定比热、焓等热力学函数，采用分段热化学多项式。
  • energy = sensibleEnthalpy：选择能量变量，求解显焓 h。
  • equationOfState = perfectGas：给出压力、温度与密度之间的关系，采用理想气体状态方程。
  • specie = specie：提供组分的基本物性。
