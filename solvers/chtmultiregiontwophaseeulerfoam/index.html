chtMultiRegionTwoPhaseEulerFoam

正在打开最新内容…

耦合求解 Euler–Euler 两相流与固体区域之间的传热。

简要介绍

流体流过受热固体时，固体内部通过导热传递热量，流体同时通过运动和导热输运热量。两侧温度相互影响，需要在独立区域中求解，并由接口条件连接。对各向同性、常物性固体及理想热接触：

ρscp,s∂tTs=∇⋅(ks∇Ts)+Qs,Ts=Tf,qn,s+qn,f=0\rho_sc_{p,s}\partial_tT_s=\nabla\cdot(k_s\nabla T_s)+Q_s,\qquad T_s=T_f,\qquad q_{n,s}+q_{n,f}=0ρs​cp,s​∂t​Ts​=∇⋅(ks​∇Ts​)+Qs​,Ts​=Tf​,qn,s​+qn,f​=0

下标 s、f 分别表示固体和流体，QsQ_sQs​ 为体积热源；两侧法向均指向各自区域外部。温度连续和热流平衡把两侧计算连接起来；存在接触热阻时，应改用相应接口关系。材料、区域几何与流动状态共同决定最终温度和换热量。

chtMultiRegionTwoPhaseEulerFoam 将两流体 Euler 传热与固体导热耦合，适合分散两相介质冷却受热固体的问题。相含率、粒径和相间换热闭合描述流体侧的平均热交换。

1. 了解算例问题

算例问题：solidQuenching2D

高温固体与较冷的两相流体接触，固体内部导热和流体侧换热共同控制冷却过程。需要分别建立固体、流体区域及其温度接口，观察固体降温和附近流体的温度、相含率变化。

算例出处：OpenCFD OpenFOAM v2512 官方教程 heatTransfer/chtMultiRegionTwoPhaseEulerFoam/solidQuenching2D。

2. 运行与准备

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/heatTransfer/chtMultiRegionTwoPhaseEulerFoam/solidQuenching2D" "$FOAM_RUN/solidQuenching2D-reference"
cd "$FOAM_RUN/solidQuenching2D-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

3. 修改配置

本例研究固体在两相流体中的冷却。水区的 phaseProperties 选择两相系统，流体各相有各自的温度和速度；固体区域另设热物性及温度。体相相变开关与壁面沸腾模型分属不同设置，应分别核对。

文件先修改什么

0.orig/water/U.liquid流体速度向量；修改入口速度或壁面运动时从此字段入手。
0.orig/solid/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。
0.orig/water/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。

4. 检查计算结果

比较温度分布、热流和浮力驱动速度。多区域接口两侧应按各自外法向核对热流；瞬态升温还要把域内储能变化计入能量收支。

按 controlDict 的写出设置打开结果目录。若 functions 或 Allrun 配置了采样、积分或统计，继续查看 postProcessing 及相应日志；没有启用的后处理不会自动产生。

    version     2.0;
    format      ascii;

    object      T;

dimensions      [ 0 0 0 1 0 0 0 ];

boundaryField

    {
        type            zeroGradient;
    }

    solid_to_water
    {
        type            compressible::turbulentTemperatureTwoPhaseRadCoupledMixed;
        value           uniform 1123;
        Tnbr            T.liquid;
        kappaMethod     solidThermo;

        qrNbr           none;

0.orig/solid/T 设置 T 的内部初值和边界条件。dimensions 为 [ 0 0 0 1 0 0 0 ]。internalField 为 uniform 1123；uniform 表示所有内部单元采用相同初值。

  • maxY 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。
  • solid_to_water 采用 compressible::turbulentTemperatureTwoPhaseRadCoupledMixed。参数为 value uniform 1123，Tnbr T.liquid，kappaMethod solidThermo，region solid，otherPhase gas，qrNbr none，qr none。

0.orig/solid/T还读取"caseDicts/setConstraintTypes"。以 #includeEtc 引入的配置来自安装环境；相对路径引用的文件需要随算例保留，修改引用内容会改变最终展开的字典。
