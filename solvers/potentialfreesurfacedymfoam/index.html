potentialFreeSurfaceDyMFoam

正在打开最新内容…

在动网格上通过波高场近似自由表面流动。

简要介绍

小幅水面波可以用相对于参考水位的高度 ζ(x,y,t)\zeta(x,y,t)ζ(x,y,t) 表示。在水面保持单值、液体不可压缩的条件下，自由表面随局部液体速度运动，满足运动学条件：

∂tζ+Ux∂xζ+Uy∂yζ=Uz在自由表面上\partial_t\zeta+U_x\partial_x\zeta+U_y\partial_y\zeta=U_z\quad\text{在自由表面上}∂t​ζ+Ux​∂x​ζ+Uy​∂y​ζ=Uz​在自由表面上

右侧为竖直速度，左侧包含局部波高变化及水平方向输运。程序用波高相关压力边界把这一关系与液体的 Navier–Stokes 计算相联系。该近似适合可由单值波高描述的水面运动，液相区域承载主要流动计算。

potentialFreeSurfaceDyMFoam 支持网格运动，用于移动边界附近仍可由单值波高表示的自由表面。波高近似与液体流动方程共同决定水面响应。

1. 了解算例问题

算例问题：oscillatingBox

箱体作周期运动，内部液体受惯性作用形成晃荡。自由表面采用该求解器的近似模型描述，重点比较水面响应与箱体运动的频率和相位。

算例出处：OpenCFD OpenFOAM v2512 官方教程 multiphase/potentialFreeSurfaceDyMFoam/oscillatingBox。

2. 运行与准备

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/multiphase/potentialFreeSurfaceDyMFoam/oscillatingBox" "$FOAM_RUN/oscillatingBox-reference"
cd "$FOAM_RUN/oscillatingBox-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

3. 修改配置

文件先修改什么
0.orig/U流体速度向量；修改入口速度或壁面运动时从此字段入手。
0.orig/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。
constant/transportProperties流体输运物性。改变材料时，在此修改黏度、密度或扩散率；各字段的量纲需保持一致。
constant/dynamicMeshDict网格更新及运动设置。运动方式、作用区域和运动参数在此定义。
constant/turbulenceProperties层流、RAS 或 LES 的选择及模型系数。切换模型后同步补齐其输运字段和数值设置。
0.orig/p_gh本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
0.orig/pointDisplacement网格点位移，m；给出固定点及运动边界的位移约束。

本例时间格式为 Euler，时间步与该格式共同决定非定常过程的时间分辨率。

system/controlDict 设置为：结束时刻 endTime 20；初始时间步 deltaT 0.001；输出依据 writeControl adjustable；输出间隔 writeInterval 0.02。非定常计算中还应结合 Courant 数检查时间步。

system/fvSolution 的 PIMPLE 设置为 nOuterCorrectors 1、nCorrectors 2、nNonOrthogonalCorrectors 0。各校正步骤及线性方程容差的完整解读列在下方。

表中列出本例首先需要检查的文件。其余字段、数值字典和完整解读见下方“完整配置与逐项解读”。

4. 检查计算结果

查看相分布、压力和各相速度，并统计各相体积或质量。VOF 关注界面位置与界面附近的寄生流，分散相模型关注滑移速度、相含率及交换源项。

按 controlDict 的写出设置打开结果目录。若 functions 或 Allrun 配置了采样、积分或统计，继续查看 postProcessing 及相应日志；没有启用的后处理不会自动产生。

初始场与边界条件

下表列出本算例提供的初始字段。带 0.orig 的路径是初始化模板，Allrun 通常先将其恢复为 0；若脚本随后执行 setFields，实际初始分布以初始化后的文件为准。

文件设置内容
0.orig/U流体速度向量；修改入口速度或壁面运动时从此字段入手。
0.orig/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。

0.orig/U

配置出处：OpenCFD OpenFOAM v2512 官方教程 multiphase/potentialFreeSurfaceDyMFoam/oscillatingBox/0.orig/U（原文件）。

foam40 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       volVectorField;
    object      U;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

dimensions      [0 1 -1 0 0 0 0];

internalField   uniform (0 0 0);

boundaryField
{
    freeSurface
    {
        type            pressureInletOutletParSlipVelocity;
        value           uniform (0 0 0);
    }

    ".*Wall"
    {
        type            noSlip;
    }

    "floatingObject.*"
    {
        type            movingWallVelocity;
        value           uniform (0 0 0);
    }

    frontAndBack
    {
        type            empty;
    }
}


// ************************************************************************* //

0.orig/U 设置 U 的内部初值和边界条件。dimensions 为 [0 1 -1 0 0 0 0]，单位为 m/s。internalField 为 uniform (0 0 0)；uniform 表示所有内部单元采用相同初值。

  • freeSurface 采用 pressureInletOutletParSlipVelocity。参数为 value uniform (0 0 0)。
  • ".*Wall" 采用 noSlip，壁面速度为零。
  • "floatingObject.*" 采用 movingWallVelocity，根据网格壁面运动计算流体壁面速度。参数为 value uniform (0 0 0)。
  • frontAndBack 采用 empty，该方向不参与空间变化，需与二维网格的 empty 面配套。

system/controlDict 中各项设置的作用如下。

  • application 设为 potentialFreeSurfaceDyMFoam：指定由 Allrun 等脚本调用的应用程序。
  • startFrom 设为 startTime：决定从给定起始时刻还是已有结果继续计算。
  • startTime 设为 0：给定起始时刻。
  • endTime 设为 20：规定计算结束的时间或稳态迭代终点。
  • deltaT 设为 0.001：设置时间步；启用自动调步后它用于起步。
  • writeControl 设为 adjustable：选择按时间步、模拟时间等事件写出结果。
  • writeInterval 设为 0.02：给出与 writeControl 配套的写出间隔。
  • purgeWrite 设为 0：控制保留多少个结果时间目录；0 表示不自动清除。
  • runTimeModifiable 设为 yes：决定运行中是否重新读取可修改的字典。
  • adjustTimeStep 设为 yes：控制是否根据 Courant 数自动调整时间步。
  • maxCo 设为 0.4：限制流动 Courant 数。
  • maxDeltaT 设为 1：限定自动时间步的上限。
  • functions/forces/writeControl 设为 writeTime：选择按时间步、模拟时间等事件写出结果。
  • functions/forces/rho 设为 rhoInf：密度，单位 kg/m³。
  • functions/poolHeight/writeControl 设为 timeStep：选择按时间步、模拟时间等事件写出结果。
  • functions/poolHeight/writeInterval 设为 1：给出与 writeControl 配套的写出间隔。

瞬态计算应同时检查时间步与写出间隔：前者影响时间离散和稳定性，后者只决定保存结果的频率。仅缩小 writeInterval 不会提高计算本身的时间分辨率。

#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

runApplication blockMesh

runApplication -s 1 topoSet

runApplication subsetMesh -overwrite c0 -patch floatingObject

runApplication -s selectBottom topoSet -dict system/topoSetDict-selectBottom

runApplication createPatch -overwrite

restore0Dir

runApplication $(getApplication)

# Require awk
command -v awk >/dev/null && {
    awk '{print $1 " " $3}' \
        postProcessing/poolHeight/0/surfaceFieldValue.dat > poolHeight_vs_time
}

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格。
  3. topoSet 按几何、网格属性和集合关系创建或修改 sets/zones。
  4. subsetMesh 按 cellSet 或 cellZone 提取子网格并映射场。结果覆盖当前网格。
  5. createPatch 把已有边界面或 faceSet 重组为指定 patch。结果覆盖当前网格。
  6. restore0Dir 将 0.orig 恢复为求解所用的 0 目录。
  7. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
  8. command 查询命令的位置，或绕过同名 shell 函数执行命令。
