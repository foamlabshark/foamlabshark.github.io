adjointOptimisationFoam

正在打开最新内容…

利用伴随灵敏度更新设计变量，执行流动优化计算。

简要介绍

几何优化先定义一个可计算目标，例如管道压损，再调整形状或区域阻力以降低目标值。若设计变量很多，伴随方法通过一组附加方程计算目标对这些变量的灵敏度。把离散流动方程写为 R(q,a)=0：

(∂R∂q)Tλ=(∂J∂q)T,dJda=∂J∂a−λT∂R∂a\left(\frac{\partial R}{\partial q}\right)^{\mathsf T}\lambda=\left(\frac{\partial J}{\partial q}\right)^{\mathsf T},\qquad\frac{{\rm d}J}{{\rm d}a}=\frac{\partial J}{\partial a}-\lambda^{\mathsf T}\frac{\partial R}{\partial a}(∂q∂R​)Tλ=(∂q∂J​)T,dadJ​=∂a∂J​−λT∂a∂R​

q 为流场变量，a 为设计变量，J 为目标函数，λ 为伴随变量。先求得流场，再求伴随场，便可据此更新设计；目标函数、边界、约束和物理模型需要在这两套计算中保持一致。

adjointOptimisationFoam 组织流场、目标、伴随灵敏度和设计更新，适合能够由已选优化组件表达的形状或拓扑优化。先确定目标与约束，再选择相应设计变量和优化方法。

1. 了解算例问题

算例问题：motorBike

来流绕过摩托车与骑手组合外形，表面附近形成边界层，后方形成分离尾流。主要结果为压力、速度、阻力及尾流结构；包含伴随设置时，还用于评价表面形状对目标函数的影响。

算例出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/adjointOptimisationFoam/sensitivityMaps/motorBike。

2. 运行与准备

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/incompressible/adjointOptimisationFoam/sensitivityMaps/motorBike" "$FOAM_RUN/motorBike-reference"
cd "$FOAM_RUN/motorBike-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

3. 修改配置

文件先修改什么
0.orig/U流体速度向量；修改入口速度或壁面运动时从此字段入手。
0.orig/pa本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
0.orig/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。
constant/transportProperties流体输运物性。改变材料时，在此修改黏度、密度或扩散率；各字段的量纲需保持一致。
constant/turbulenceProperties层流、RAS 或 LES 的选择及模型系数。切换模型后同步补齐其输运字段和数值设置。
0.orig/Ua本模型的初始字段。internalField 设置内部初值，boundaryField 为每个网格边界分别设置条件。
0.orig/nuTildaSpalart–Allmaras 输运变量，m²/s；不能用 k 或 nut 的入口值直接替代。

本例时间格式为 steadyState，按稳态迭代处理；controlDict 中的时间编号用于组织迭代与输出。

system/controlDict 设置为：结束编号 endTime 2000；编号增量 deltaT 1；输出依据 writeControl timeStep；输出间隔 writeInterval 1000。

当前启用 SpalartAllmaras，需检查 nuTilda 及其壁面条件。目录中保留的其他模型字段仅在切换到相应模型时使用。

表中列出本例首先需要检查的文件。其余字段、数值字典和完整解读见下方“完整配置与逐项解读”。

4. 检查计算结果

对照速度剖面、流量和压力差；有分离时检查回流区位置。稳态监测量应趋于稳定，入口和出口的净质量通量应闭合。

按 controlDict 的写出设置打开结果目录。若 functions 或 Allrun 配置了采样、积分或统计，继续查看 postProcessing 及相应日志；没有启用的后处理不会自动产生。

0.orig/U 设置 U 的内部初值和边界条件。dimensions 为 [0 1 -1 0 0 0 0]，单位为 m/s。internalField 为 uniform $flowVelocity；uniform 表示所有内部单元采用相同初值。

  • outlet 采用 inletOutlet，出流时外推，回流时采用 inletValue。参数为 inletValue uniform (0 0 0)，value $internalField。
  • lowerWall 采用 fixedValue，边界始终采用给定的 value。参数为 value $internalField。
  • motorBikeGroup 采用 noSlip，壁面速度为零。

0.orig/U还读取"include/initialConditions"、"caseDicts/setConstraintTypes"、"include/fixedInlet"、"include/frontBackUpperPatches"。以 #includeEtc 引入的配置来自安装环境；相对路径引用的文件需要随算例保留，修改引用内容会改变最终展开的字典。

  • purgeWrite 设为 1：控制保留多少个结果时间目录；0 表示不自动清除。
  • runTimeModifiable 设为 true：决定运行中是否重新读取可修改的字典。

Allrun：官方预处理、求解和后处理执行顺序。

Allrun

配置出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/adjointOptimisationFoam/sensitivityMaps/motorBike/Allrun（原文件）。

Bash / 终端44 行
#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

# Alternative decomposeParDict name:
decompDict="-decomposeParDict system/decomposeParDict.20"
## Standard decomposeParDict name:
# unset decompDict

# copy motorbike surface from resources directory
cp -f "$FOAM_TUTORIALS"/resources/geometry/motorBike.obj.gz constant/triSurface/
runApplication surfaceFeatureExtract

runApplication blockMesh

runApplication $decompDict decomposePar

# Using distributedTriSurfaceMesh?
if foamDictionary -entry geometry -value system/snappyHexMeshDict | \
   grep -q distributedTriSurfaceMesh
then
    echo "surfaceRedistributePar does not need to be run anymore"
    echo " - distributedTriSurfaceMesh will do on-the-fly redistribution"
fi

runParallel $decompDict snappyHexMesh -overwrite

#- For non-parallel running: - set the initial fields
# restore0Dir

#- For parallel running: set the initial fields
restore0Dir -processor

runParallel $decompDict patchSummary
runParallel $decompDict potentialFoam -writephi
runParallel $decompDict checkMesh -writeFields '(nonOrthoAngle)' -constant

runParallel $decompDict $(getApplication)

runApplication reconstructParMesh -constant
runApplication reconstructPar -latestTime

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. cp 复制文件或目录。
  3. surfaceFeatureExtract 从表面提取特征线，供 snappyHexMesh 控制棱边细化。
  4. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格。
  5. decomposePar 把网格和场划分到多个处理器子域。
  6. foamDictionary 读取、修改和展开 OpenFOAM 字典。
  7. grep 按文本模式检索文件。
  8. surfaceRedistributePar 按并行分区重新分配表面三角形，使各进程获得所需几何数据；run 切换到个人算例目录；echo 显示环境变量或简单文本。
  9. echo 显示环境变量或简单文本。
  10. snappyHexMesh 细化背景网格，贴合几何表面，并按设置生成边界层。结果覆盖当前网格。通过并行包装函数执行，进程数与分区设置配套。
  11. restore0Dir 将 0.orig 恢复为求解所用的 0 目录。
  12. patchSummary 列出各边界patch上的字段边界条件。通过并行包装函数执行，进程数与分区设置配套。
  13. potentialFoam 求解势流方程，常用于初始化速度与通量。通过并行包装函数执行，进程数与分区设置配套。
  14. checkMesh 检查网格拓扑、几何形状与质量，并定位问题区域。通过并行包装函数执行，进程数与分区设置配套。
  15. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
  16. reconstructParMesh 从处理器子域重构网格和寻址关系。
  17. reconstructPar 把并行结果的字段重构到完整案例。只读取最新结果时刻。
