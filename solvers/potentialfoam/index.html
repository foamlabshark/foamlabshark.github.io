potentialFoam

正在打开最新内容…

求解势流方程，常用于初始化速度与通量。

简要介绍

在密度近似恒定、流动可视为无旋的区域，速度可由一个标量函数的梯度表示。这个函数称为速度势；等势面的法向就是速度方向。把无旋条件与不可压缩连续性结合，可得到势流的 Laplace 方程：

U=∇Ψ,∇×U=0,∇⋅U=0 ⟹ ∇2Ψ=0\mathbf U=\nabla\Psi,\qquad\nabla\times\mathbf U=0,\qquad\nabla\cdot\mathbf U=0\ \Longrightarrow\ \nabla^2\Psi=0U=∇Ψ,∇×U=0,∇⋅U=0 ⟹ ∇2Ψ=0

Ψ 的单位为 m²/s。边界上的流入、流出和不穿透条件共同决定势函数，从而得到绕过物体的近似流动。这个描述适合研究无旋流动，也常用于生成与边界流量相协调的初始速度。

v2512 的程序从当前速度构造面体积通量，求解校正势 Φ，再减去其梯度对应的通量。连续形式的校正关系为：

∇⋅(a∇Φ)=∇⋅U0,Uc=U0−a∇Φ\nabla\cdot(a\nabla\Phi)=\nabla\cdot\mathbf U_0,\qquad\mathbf U_c=\mathbf U_0-a\nabla\Phi∇⋅(a∇Φ)=∇⋅U0​,Uc​=U0​−a∇Φ

U₀ 为校正前的速度，a 表示通量校正中的面系数，普通有效网格上取 1；重叠网格版本还使用 faceMask 标识参与计算的面。右侧是原有通量的不平衡量，求解 Φ 是为了消除该不平衡。程序在有限体积网格上先校正面通量，再重构单元速度。大写 Phi 是校正势，小写 phi 是面体积通量，二者的物理含义和单位不同。

potentialFoam 在普通有限体积网格上建立流量协调的速度场，并按选项输出 Phi、phi 或近似压力。它适合定密度无旋流动和黏性求解前的初始场生成，之后的边界层与湍流演化由所选流动求解器计算。

1. 了解算例问题

算例问题：cylinder

来流绕过圆柱，通过速度势建立近似无旋流场。算例依据边界条件计算速度和面通量，可用于检查势流分布或为后续黏性流动提供初始场；重叠网格版本还检验背景区域与圆柱网格之间的连接。

算例出处：OpenCFD OpenFOAM v2512 官方教程 basic/potentialFoam/cylinder。

2. 运行与准备

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/basic/potentialFoam/cylinder" "$FOAM_RUN/cylinder-reference"
cd "$FOAM_RUN/cylinder-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

3. 修改配置

速度势求解用于获得近似无旋、满足通量约束的初始流场。物体壁面设为不可穿透边界；所得流场适合初始化，不能据此获得黏性边界层或分离阻力。

文件先修改什么
0.orig/U流体速度向量；修改入口速度或壁面运动时从此字段入手。
0.orig/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。
system/decomposeParDict并行分区数量和方法；运行进程数应与 numberOfSubdomains 一致。

本例时间格式为 steadyState，按稳态迭代处理；controlDict 中的时间编号用于组织迭代与输出。

system/controlDict 设置为：结束编号 endTime 1；编号增量 deltaT 1；输出依据 writeControl timeStep；输出间隔 writeInterval 1。

表中列出本例首先需要检查的文件。其余字段、数值字典和完整解读见下方“完整配置与逐项解读”。

4. 检查计算结果

比较被求解字段的空间分布与边界值；扩散问题可进一步核对稳态通量或瞬态解析解，势流结果则用于检查流向、通量及后续初始化。

按 controlDict 的写出设置打开结果目录。若 functions 或 Allrun 配置了采样、积分或统计，继续查看 postProcessing 及相应日志；没有启用的后处理不会自动产生。

完整配置与逐项解读

初始场与边界条件

下表列出本算例提供的初始字段。带 0.orig 的路径是初始化模板，Allrun 通常先将其恢复为 0；若脚本随后执行 setFields，实际初始分布以初始化后的文件为准。

文件设置内容
0.orig/U流体速度向量；修改入口速度或壁面运动时从此字段入手。
0.orig/p压力场；dimensions 为 [0 2 -2 0 0 0 0] 时是 p/ρ，不能直接填入以 Pa 表示的压力。
0.orig/U：速度向量，m/s。

0.orig/U

配置出处：OpenCFD OpenFOAM v2512 官方教程 basic/potentialFoam/cylinder/0.orig/U（原文件）。

foam49 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       volVectorField;
    object      U;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

dimensions      [0 1 -1 0 0 0 0];

internalField   uniform (0 0 0);

boundaryField
{
    down
    {
        type            symmetryPlane;
    }

    right
    {
        type            zeroGradient;
    }

    up
    {
        type            symmetryPlane;
    }

    left
    {
        type            uniformFixedValue;
        uniformValue    constant (1 0 0);
    }

    cylinder
    {
        type            symmetry;
    }

    defaultFaces
    {
        type            empty;
    }
}


// ************************************************************************* //

0.orig/U 设置 U 的内部初值和边界条件。dimensions 为 [0 1 -1 0 0 0 0]，单位为 m/s。internalField 为 uniform (0 0 0)；uniform 表示所有内部单元采用相同初值。

  • down、up 采用 symmetryPlane，对整个平面对称面施加对称约束。
  • right 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。
  • left 采用 uniformFixedValue，用时间函数设置整个入口的速度。参数为 uniformValue constant (1 0 0)。
  • cylinder 采用 symmetry，按局部面法向施加对称约束。
  • defaultFaces 采用 empty，该方向不参与空间变化，需与二维网格的 empty 面配套。

system/fvSchemes按算子名称选择离散格式。求解器调用的算子名称需要与这里的键相符。

条目本例设置解读
ddtSchemes/defaultsteadyState时间导数的默认设置，忽略时间导数，用于稳态迭代。
gradSchemes/defaultleastSquares空间梯度的默认设置。
divSchemes/defaultnone散度及对流项的默认设置，不提供默认格式，所需算子应单独列出。
divSchemes/div(phi,U)bounded Gauss linear散度及对流项；括号内给出通量与所输运的量。
divSchemes/div(div(phi,U))Gauss linear散度及对流项；括号内给出通量与所输运的量。
laplacianSchemes/defaultGauss linear corrected扩散项的默认设置；包含非正交网格修正。
interpolationSchemes/defaultlinear单元中心到面的插值的默认设置。
snGradSchemes/defaultcorrected面法向梯度的默认设置；包含非正交网格修正。

system/fvSolution

    Phi
    {
        solver          GAMG;
        smoother        DIC;

system/fvSolution分别控制单个线性方程的求解和各物理场之间的耦合。带引号的字段名可使用正则表达式，一组设置因而可以覆盖多个字段。

system/fvSolution 的线性求解设置
字段或匹配规则本例设置的作用

  • potentialFlow/nNonOrthogonalCorrectors = 3：压力或扩散方程的非正交校正次数。

时间、迭代与输出设置

system/controlDict

程序名称、时间步、终止时刻与写出控制。

配置出处：OpenCFD OpenFOAM v2512 官方教程 basic/potentialFoam/cylinder/system/controlDict（原文件）。

foam125 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      controlDict;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

application     potentialFoam;

startFrom       latestTime;

startTime       0;

stopAt          nextWrite;

endTime         1;

deltaT          1;

writeControl    timeStep;

writeInterval   1;

purgeWrite      0;

writeFormat     ascii;

writePrecision  6;

writeCompression off;

timeFormat      general;

timePrecision   6;

runTimeModifiable true;

functions
{
    error
    {
        name    error;
        type    coded;
        libs    (utilityFunctionObjects);

        codeEnd
        #{
            // Lookup U
            Info<< "Looking up field U\n" << endl;
            const auto& U = mesh().lookupObject<volVectorField>("U");

            Info<< "Reading inlet velocity uInfX\n" << endl;

            scalar ULeft = 0.0;
            label leftI = mesh().boundaryMesh().findPatchID("left");
            const auto& fvp = U.boundaryField()[leftI];
            if (fvp.size())
            {
                ULeft = fvp[0].x();
            }
            reduce(ULeft, maxOp<scalar>());

            dimensionedScalar uInfX("uInfx", dimVelocity, ULeft);

            Info<< "U at inlet = " << uInfX.value() << " m/s" << endl;


            scalar magCylinder = 0.0;
            label cylI = mesh().boundaryMesh().findPatchID("cylinder");
            const auto& cylFvp = mesh().C().boundaryField()[cylI];
            if (cylFvp.size())
            {
                magCylinder = mag(cylFvp[0]);
            }
            reduce(magCylinder, maxOp<scalar>());

            dimensionedScalar radius("radius", dimLength, magCylinder);

            Info<< "Cylinder radius = " << radius.value() << " m" << endl;

            volVectorField UA
            (
                IOobject
                (
                    "UA",
                    mesh().time().timeName(),
                    U.mesh(),
                    IOobject::NO_READ,
                    IOobject::AUTO_WRITE
                ),
                U
            );

            Info<< "\nEvaluating analytical solution" << endl;

            const volVectorField& centres = UA.mesh().C();
            volScalarField magCentres(mag(centres));
            volScalarField theta(acos((centres & vector(1,0,0))/magCentres));

            volVectorField cs2theta
            (
                cos(2*theta)*vector(1,0,0)
              + sin(2*theta)*vector(0,1,0)
            );

            UA = uInfX*(dimensionedVector(vector(1,0,0))
              - pow((radius/magCentres),2)*cs2theta);

            // Force writing of UA (since time has not changed)
            UA.write();

            volScalarField error("error", mag(U-UA)/mag(UA));

            Info<<"Writing relative error in U to " << error.objectPath()
                << endl;

            error.write();
        #};
    }
}


// ************************************************************************* //

system/controlDict 中各项设置的作用如下。

  • application 设为 potentialFoam：指定由 Allrun 等脚本调用的应用程序。
  • startFrom 设为 latestTime：决定从给定起始时刻还是已有结果继续计算。
  • startTime 设为 0：给定起始时刻。
  • endTime 设为 1：规定计算结束的时间或稳态迭代终点。
  • deltaT 设为 1：设置时间步；启用自动调步后它用于起步。
  • writeControl 设为 timeStep：选择按时间步、模拟时间等事件写出结果。
  • writeInterval 设为 1：给出与 writeControl 配套的写出间隔。
  • purgeWrite 设为 0：控制保留多少个结果时间目录；0 表示不自动清除。
  • runTimeModifiable 设为 true：决定运行中是否重新读取可修改的字典。

查看官方原文件 · 下载此配置文件

熊猫说：本例采用 steadyState 时间格式。endTime 和 deltaT 用于控制稳态迭代及写出计数，不能把输出目录名直接解释为物理演化时间。收敛还需结合残差和流量、压降等监测量判断。

初始化与并行准备

文件执行作用
system/decomposeParDict并行分区数量和方法；运行进程数应与 numberOfSubdomains 一致。
Allrun：官方预处理、求解和后处理执行顺序。

Allrun

配置出处：OpenCFD OpenFOAM v2512 官方教程 basic/potentialFoam/cylinder/Allrun（原文件）。

Bash / 终端16 行
#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

canCompile || exit 0    # Dynamic code

restore0Dir

runApplication blockMesh

runApplication $(getApplication) -withFunctionObjects -writePhi -writephi -writep

runApplication postProcess -func streamFunction

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. canCompile 检查 make、wmake 和 C++ 编译器是否可用。
  3. restore0Dir 将 0.orig 恢复为求解所用的 0 目录。
  4. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格。
  5. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
  6. postProcess 在已有结果上执行功能对象。
