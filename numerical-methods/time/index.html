时间离散 · Euler、backward、CrankNicolson

正在打开最新内容…

在 fvSchemes 的 ddtSchemes 中设置时间导数离散；稳态问题使用 steadyState。

简要介绍

时间离散格式规定时间导数的近似方法。Euler、backward 和 CrankNicolson 用于非定常推进；steadyState 忽略时间导数，用于稳态迭代。

选用格式后，还需确定时间步和输出间隔。应通过减小时间步比较主要结果，区分时间离散误差与每个时间步内的方程求解误差。

对固定网格、恒定时间步，Euler 与 backward 的时间导数近似分别为：

∂tq∣n+1≈qn+1−qnΔt,∂tq∣n+1≈3qn+1−4qn+qn−12Δt\left.\partial_t q\right|^{n+1}\approx\frac{q^{n+1}-q^n}{\Delta t},\qquad\left.\partial_t q\right|^{n+1}\approx\frac{3q^{n+1}-4q^n+q^{n-1}}{2\Delta t}∂t​q∣n+1≈Δtqn+1−qn​,∂t​q∣n+1≈2Δt3qn+1−4qn+qn−1​

Euler 为一阶，backward 为二阶后向格式；变时间步时 backward 的系数随时间步比调整。CrankNicolson 对新旧时刻贡献加权，并可通过偏心系数增加稳健性。时间格式只控制离散误差的一部分，还需缩小时间步验证瞬态结果是否稳定。

设置位置与参数

算例问题：cavity

封闭方腔的顶盖沿切向运动，其他壁面保持静止，顶盖通过黏性作用带动腔内流体。计算产生主涡和角部回流，用于检查速度、压力以及网格分辨率对流动结构的影响。

算例出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/icoFoam/cavity/cavity。

本页重点配置：incompressible/icoFoam/cavity/cavity/system/fvSchemes。下表说明各条目的作用。完整算例的网格、初始场和配套模型见后文。

条目含义与设置
Euler一阶隐式时间离散。
backward二阶后向差分。
CrankNicolson可通过偏心系数混合到 Euler。
steadyState不计算时间导数。

官方配置示例

system/fvSchemes

每个方程项的空间和时间离散格式。

配置出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/icoFoam/cavity/cavity/system/fvSchemes（原文件）。

foam43 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      fvSchemes;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

ddtSchemes
{
    default         Euler;
}

gradSchemes
{
    default         Gauss linear;
    grad(p)         Gauss linear;
}

divSchemes
{
    default         none;
    div(phi,U)      Gauss linear;
}

laplacianSchemes
{
    default         Gauss linear orthogonal;
}

interpolationSchemes
{
    default         linear;
}

snGradSchemes
{
    default         orthogonal;
}


// ************************************************************************* //

system/fvSchemes按算子名称选择离散格式。求解器调用的算子名称需要与这里的键相符。

条目本例设置解读
ddtSchemes/defaultEuler时间导数的默认设置，采用一阶隐式时间离散。
gradSchemes/defaultGauss linear空间梯度的默认设置。
gradSchemes/grad(p)Gauss linear空间梯度。
divSchemes/defaultnone散度及对流项的默认设置，不提供默认格式，所需算子应单独列出。
divSchemes/div(phi,U)Gauss linear散度及对流项；括号内给出通量与所输运的量。
laplacianSchemes/defaultGauss linear orthogonal扩散项的默认设置。
interpolationSchemes/defaultlinear单元中心到面的插值的默认设置。
snGradSchemes/defaultorthogonal面法向梯度的默认设置。

文件作用

0/U

配置出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/icoFoam/cavity/cavity/0/U（原文件）。

foam34 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       volVectorField;
    object      U;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

dimensions      [0 1 -1 0 0 0 0];

internalField   uniform (0 0 0);

boundaryField
{
    movingWall
    {
        type            fixedValue;
        value           uniform (1 0 0);
    }

    fixedWalls
    {
        type            noSlip;
    }

    frontAndBack
    {
        type            empty;
    }
}


// ************************************************************************* //

0/U 设置 U 的内部初值和边界条件。dimensions 为 [0 1 -1 0 0 0 0]，单位为 m/s。internalField 为 uniform (0 0 0)；uniform 表示所有内部单元采用相同初值。

  • movingWall 采用 fixedValue，边界始终采用给定的 value。参数为 value uniform (1 0 0)。
  • fixedWalls 采用 noSlip，壁面速度为零。
  • frontAndBack 采用 empty，该方向不参与空间变化，需与二维网格的 empty 面配套。

system/fvSolution：线性求解器、耦合循环、容差与松弛。

system/fvSolution

配置出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/icoFoam/cavity/cavity/system/fvSolution（原文件）。

foam44 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      fvSolution;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

solvers
{
    p
    {
        solver          PCG;
        preconditioner  DIC;
        tolerance       1e-06;
        relTol          0.05;
    }

    pFinal
    {
        $p;
        relTol          0;
    }

    U
    {
        solver          smoothSolver;
        smoother        symGaussSeidel;
        tolerance       1e-05;
        relTol          0;
    }
}

PISO
{
    nCorrectors     2;
    nNonOrthogonalCorrectors 0;
    pRefCell        0;
    pRefValue       0;
}


// ************************************************************************* //

system/fvSolution分别控制单个线性方程的求解和各物理场之间的耦合。带引号的字段名可使用正则表达式，一组设置因而可以覆盖多个字段。

system/fvSolution 的线性求解设置
字段或匹配规则本例设置的作用
psolver PCG：线性方程采用 PCG 方法；preconditioner DIC：选择线性方程的预条件方法；tolerance 1e-06：线性方程绝对残差阈值；relTol 0.05：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
pFinalrelTol 0：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
Usolver smoothSolver：线性方程采用 smoothSolver 方法；smoother symGaussSeidel：选择光顺方法；tolerance 1e-05：线性方程绝对残差阈值；relTol 0：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
  • PISO/nCorrectors = 2：每轮压力速度耦合中的压力校正次数。
  • PISO/nNonOrthogonalCorrectors = 0：压力或扩散方程的非正交校正次数。
  • PISO/pRefCell = 0：设置压力参考单元。
  • PISO/pRefValue = 0：设置该单元的压力参考值。

复制与运行完整算例

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/incompressible/icoFoam/cavity" "$FOAM_RUN/cavity-reference"
cd "$FOAM_RUN/cavity-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

Allrun：官方预处理、求解和后处理执行顺序。

Allrun

Bash / 终端95 行
#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

cavityCases="
cavity
cavityFine
cavityGrade
cavityHighRe
cavityClipped
"

runMapFields()
{
    echo "Running mapFields from $1 to $2"
    mapFields "$1" -case "$2" -sourceTime latestTime > "$2"/log.mapFields 2>&1
}

runMapFieldsConsistent()
{
    echo "Running mapFields from $1 to $2"
    mapFields "$1" -case "$2" -sourceTime latestTime -consistent > "$2"/log.mapFields 2>&1
}

copySolutionDirs()
{
    echo "Copying $2/0* directory to $1"
    cp -rf "$2"/0* "$1"
}

setCavityFine()
{
    blockMeshDict="$caseName/system/blockMeshDict"
    controlDict="$caseName/system/controlDict"
    sed s/"20 20 1"/"41 41 1"/g "$blockMeshDict" > temp.$$
    mv -f temp.$$ "$blockMeshDict"
    sed \
        -e s/"\(startTime[ \t]*\) 0;"/"\1 0.5;"/g \
        -e s/"\(endTime[ \t]*\) 0.5;"/"\1 0.7;"/g \
        -e s/"\(deltaT[ \t]*\) 0.005;"/"\1 0.0025;"/g \
        -e s/"\(writeControl[ \t]*\) timeStep;"/"\1 runTime;"/g \
        -e s/"\(writeInterval[ \t]*\) 20;"/"\1 0.1;"/g \
        "$controlDict" > temp.$$
    mv -f temp.$$ "$controlDict"
}

setCavityHighRe()
{
    echo "Setting cavityHighRe to generate a secondary vortex"
    controlDict="$caseName/system/controlDict"
    transportProperties="$caseName/constant/transportProperties"
    sed \
        -e s/"\(startFrom[ \t]*\) startTime;"/"\1 latestTime;"/g \
        -e s/"\(endTime[ \t]*\) 0.5;"/"\1 2.0;"/g \
        "$controlDict" > temp.$$
    mv -f temp.$$ "$controlDict"
    sed s/"0.01"/"0.001"/g "$transportProperties" > temp.$$
    mv -f temp.$$ "$transportProperties"
}


unset previousCase
for caseName in $cavityCases
do
    case "$caseName" in
    cavityFine)
        cloneCase cavity "$caseName"
        setCavityFine
        ;;

    cavityHighRe)
        cloneCase cavity "$caseName"
        setCavityHighRe
        copySolutionDirs "$caseName" cavity
        ;;
    esac

    ( cd "$caseName" && runApplication blockMesh )

    case "$caseName" in
    cavityFine | cavityGrade)
        runMapFieldsConsistent "$previousCase" "$caseName"
        ;;
    cavityClipped)
        cp -rf "$caseName"/0 "$caseName"/0.5
        runMapFields cavity "$caseName"
        ;;
    esac

    previousCase="$caseName"
    ( cd "$caseName" && runApplication $(getApplication) )
done

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. mapFields 将一个案例的场映射到当前目标案例；echo 显示环境变量或简单文本。
  3. mapFields 将一个案例的场映射到当前目标案例。
  4. echo 显示环境变量或简单文本。
  5. cp 复制文件或目录。
  6. mv 移动文件或目录，也可用于重命名。
  7. cloneCase 复制需要的算例文件。
  8. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格；cd 切换当前工作目录。
  9. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
