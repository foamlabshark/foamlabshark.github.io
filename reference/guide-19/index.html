19.1 场文件的结构

OpenFOAM 字典25 行
FoamFile { version 2.0; format ascii; class volVectorField; object U; }

dimensions      [0 1 -1 0 0 0 0];        // 量纲
internalField   uniform (0 0 0);         // 内部场初值

boundaryField
{
    inlet
    {
        type            fixedValue;
        value           uniform (1 0 0);
    }
    outlet
    {
        type            zeroGradient;
    }
    walls
    {
        type            noSlip;
    }
    frontAndBack
    {
        type            empty;
    }
}

三条强制规则：① boundaryField 里的 patch 名必须与 constant/polyMesh/boundary 完全对应（可用正则），漏一个就报 Cannot find patchField entry for xxx；② empty、symmetryPlane、wedge、cyclic 这类约束型边界，场里的 type 必须与网格里的 type 一致，否则报错；③ 很多边界条件即使值用不上也要写 value 一行（它是”当前值”的存储位置，重启时要用）。

19.2 通用边界条件

type数学含义用在
fixedValueφ\varphiφ= 给定值（Dirichlet）进口速度、给定温度
zeroGradient∂φ/∂n=0\partial \varphi /\partial n = 0∂φ/∂n=0（Neumann）出口、绝热壁
fixedGradient∂φ/∂n\partial \varphi /\partial n∂φ/∂n= 给定值给定热流
mixedDirichlet 与 Neumann 的加权混合大多数复合条件的基类
calculated由其他场算出，不独立求解nut、rho 等
noSlipU=0U = 0U=0（等价于 fixedValue uniform (0 0 0)）静止壁面
slip法向为 0，切向零梯度无摩擦壁
symmetry / symmetryPlane对称对称面
empty该方向不求解二维算例前后面
wedge轴对称楔形算例
cyclic周期性槽道流、叶栅
cyclicAMI非匹配周期旋转机械交界面
processor并行内部边界自动生成，不用手写

19.3 速度 U 的常用边界条件

type作用示例
fixedValue给定速度value uniform (10 0 0);
noSlip无滑移壁——
inletOutlet流入时用 inletValue，流出时零梯度防回流发散，出口首选
pressureInletOutletVelocity由压力边界推速度，允许双向配 totalPressure 用
pressureInletVelocity由通量反推速度只允许流入
flowRateInletVelocity给定体积/质量流量volumetricFlowRate 0.01;
swirlFlowRateInletVelocity带旋流的流量入口旋流燃烧器
movingWallVelocity动网格壁面（自动扣除网格运动通量）用于随网格运动的壁面，按网格速度更新速度边界。
rotatingWallVelocity旋转壁origin,axis,omega
translatingWallVelocity平移壁顶盖驱动腔
freestreamVelocity远场（自动判进出）外流远场
codedFixedValue自定义分布（见 10.3）抛物线入口
timeVaryingMappedFixedValue从文件读随时间/空间变化的入口用实测或前驱算例数据
turbulentDFSEMInlet合成湍流入口（LES 用）生成带脉动的入口
OpenFOAM 字典15 行
// 典型出口写法：允许流出，万一回流也不会炸
outlet
{
    type            inletOutlet;
    inletValue      uniform (0 0 0);
    value           uniform (0 0 0);
}

// 给定流量入口
inlet
{
    type            flowRateInletVelocity;
    volumetricFlowRate  0.001;      // m³/s；也可用 massFlowRate

}

19.4 压力 p / p_rgh 的常用边界条件

type作用
zeroGradient壁面标准做法（不可压）
fixedValue出口给定压力（不可压时值是 p/ρp/\rhop/ρ）
totalPressure给定总压，静压随速度自动调整
fixedFluxPressure壁面与动网格的正确做法：保证边界通量与速度边界一致
prghPressure / prghTotalPressure多相流的 p_rgh（已扣除静水压）
freestreamPressure远场
waveTransmissive无反射出口（可压缩，防激波反射回来）
OpenFOAM 字典14 行
// 不可压出口
outlet { type fixedValue; value uniform 0; }

// 壁面（含浮力/动网格时必须这样写）
walls  { type fixedFluxPressure; value uniform 0; }

// 可压超声速出口，防止反射
outlet
{
    type            waveTransmissive;
    field           p;
    gamma           1.4;
    value           uniform 1e5;
}

压力边界应与离散动量方程和法向通量约束一致。fixedFluxPressure 可在支持该更新流程的求解器中设置与通量相容的压力梯度；含重力或网格运动时尤其需要核对 p 与 p_rgh 的定义。zeroGradient 是否合理，应按具体方程和边界条件判断。

p 和 p_rgh 的区别：多相流和浮力问题里求解的是 prgh=p−ρg⋅hp_{\mathrm{rgh}}=p-\rho\boldsymbol g\cdot\boldsymbol hprgh​=p−ρg⋅h（扣掉静水压），这样数值上更好解。你在 0/ 里给的是 p_rgh，p 由程序算出。边界条件要给在 p_rgh 上。

// 0/k
inlet
{
    type        turbulentIntensityKineticEnergyInlet;
    intensity   0.05;                 // 湍流度 5%
    value       uniform 0.375;
}
walls  { type kqRWallFunction; value uniform 0.375; }

// 0/epsilon
inlet
{
    type        turbulentMixingLengthDissipationRateInlet;
    mixingLength 0.007;               // 特征长度的 7% 是常用估计

入口湍流量可以根据湍流强度和特征长度估算；下式依赖各向同性及所选湍流模型的常见假设，实验数据可用时应优先核对：

k=1.5(U⋅I)2k = 1.5 (U\cdot I)^{2}k=1.5(U⋅I)2，I 是湍流度（管流取 5%，风洞取 1%）

ε=Cμ0.75k1.5l\varepsilon=\frac{C_\mu^{0.75}k^{1.5}}{l}ε=lCμ0.75​k1.5​，Cμ=0.09C_\mu = 0.09Cμ​=0.09，l≈0.07l \approx 0.07l≈0.07× 水力直径

ω=k0.5Cμ0.25l\omega=\frac{k^{0.5}}{C_\mu^{0.25}l}ω=Cμ0.25​lk0.5​

壁面函数怎么选

壁面函数y+y^{+}y+ 适用范围说明
nutkWallFunction30–300标准壁函数，基于 k
nutUSpaldingWallFunction全 y+y^{+}y+连续壁函数，网格 y+y^{+}y+ 不好控制时用它最省心
nutUWallFunction30–300基于速度
nutLowReWallFunctiony+<1y^{+} < 1y+<1解析近壁

先看 y+y^{+}y+ 再选：跑几步后 simpleFoam -postProcess -func yPlus -latestTime，看 postProcessing/yPlus/ 里的范围。y+y^{+}y+ 落在 5–30 的缓冲层是最糟的情况（两种做法都不准），要么加密到 y+<1y^{+}<1y+<1，要么放粗到 y+>30y^{+}>30y+>30——或者直接用 nutUSpaldingWallFunction。

19.7 多相流的 alpha

OpenFOAM 字典11 行
// 0/alpha.water
inlet   { type fixedValue; value uniform 1; }
outlet  { type inletOutlet; inletValue uniform 0; value uniform 0; }
walls
{
    type            constantAlphaContactAngle;   // 接触角（毛细现象重要时）
    theta0          90;
    limit           gradient;
    value           uniform 0;
}
atmosphere { type inletOutlet; inletValue uniform 0; value uniform 0; }

inlet 采用 fixedValue，边界始终采用给定的 value。规定值为 uniform 1，求解中保持该值。

outlet 采用 inletOutlet，出流时外推，回流时采用 inletValue。发生回流时采用 uniform 0。value=uniform 0 为初始化所用的边界值，后续值按该类型更新。

walls 采用 constantAlphaContactAngle，通过固定接触角控制壁面附近的界面法向。value=uniform 0 为初始化所用的边界值，后续值按该类型更新。

atmosphere 采用 inletOutlet，出流时外推，回流时采用 inletValue。发生回流时采用 uniform 0。value=uniform 0 为初始化所用的边界值，后续值按该类型更新。

19.8 时变与外部数据

OpenFOAM 字典26 行
// ① 用表格给随时间变化的值
inlet
{
    type            uniformFixedValue;
    uniformValue    table ((0 (0 0 0)) (1 (10 0 0)) (5 (10 0 0)));
}

// ② 从文件读随时间和空间变化的入口（前驱算例 / 实测数据）
inlet
{
    type            timeVaryingMappedFixedValue;
    offset          (0 0 0);
    setAverage      off;
}
// 数据放在 constant/boundaryData/inlet/{points, 0/U, 0.1/U, ...}

// ③ 把另一处的场映射过来（回收入口，做周期性湍流入口）
inlet
{
    type            mapped;
    field           U;
    setAverage      true;
    average         (10 0 0);
    interpolationScheme cell;
    value           uniform (10 0 0);
}

inlet 采用 uniformFixedValue，用时间函数设置整个入口的速度。value=uniform (10 0 0) 为初始化所用的边界值，后续值按该类型更新。

inlet 采用 timeVaryingMappedFixedValue，将离散位置和时刻给出的边界数据插值到计算边界。value=uniform (10 0 0) 为初始化所用的边界值，后续值按该类型更新。

19.9 边界条件查询方法

Bash / 终端4 行
foamHelp boundary -field U | less          # 本机所有可用类型
pimpleFoam -listVectorBCs                  # 同上，另一个入口
find $FOAM_SRC -name "*inletOutlet*"       # 找源码
grep -rl "inletOutlet" $FOAM_TUTORIALS/incompressible --include=U | head   # 找用例

找到使用该边界条件的官方算例，参考其中的完整配置，再调整字段名和参数值。
