snappyHexMeshDict

正在打开最新内容…

设置表面几何、局部细化、表面贴合和边界层，供 snappyHexMesh 生成贴体网格。

简要介绍

这个字典组织从背景网格到复杂贴体网格的全过程：指定几何表面、细化区域、表面贴合及边界层。通常先准备基础网格和几何文件，再按各阶段调整分辨率、保留区域与质量限制，最后得到对应物体外形的体网格。

位置：system/snappyHexMeshDict

参数说明

条目含义
type运行时选择的模型或操作类型，同一个关键字在不同子字典中具有不同注册表。
expansionRatio相邻挤出层的厚度增长比例。
regions几何选择区域或多区域列表，按所在字典的格式填写。
cellZone源项、运动或材料区域所引用的单元区名称。

各阶段的细化与质量设置

castellatedMeshControls 设置切割细化，snapControls 设置表面贴合，addLayersControls 设置边界层，meshQualityControls 设置网格质量。

参数说明
geometry.<几何名>.min / maxsearchableBox 的两个对角点。几何文件名、区域名及 dummy、all 等选择名填写为对应几何的名称。
castellatedMeshControls.maxLoadUnbalance并行细化允许的负载不均衡程度；与 maxLocalCells 一起影响重新分配的时机。
snapControls.implicitFeatureSnap根据几何隐式识别特征并贴合；与 explicitFeatureSnap 的显式 eMesh 路径不同。
snapControls.multiRegionFeatureSnap显式特征贴合时考虑表面区域之间的特征交界。
castellatedMeshControls.useTopologicalSnapDetection是否用拓扑方式检测可能造成贴合问题的单元；需结合局部薄隙和单元删除结果检查。
refinementSurfaces.<表面>.patchInfo.inGroups生成边界所属的 patch 分组列表，例如 (walls)，方便后续批量选择。
addLayersControls.nSmoothSurfaceNormals / nSmoothNormals表面法向与内部挤出方向的平滑迭代次数。
addLayersControls.nSmoothThickness层厚分布平滑的迭代次数。
addLayersControls.maxFaceThicknessRatio限制相对面尺度的挤出厚度，防止面扭曲导致无效层。
addLayersControls.maxThicknessToMedialRatio层厚相对于局部中轴距离的比例上限，用于控制狭窄区域的加层厚度。
addLayersControls.minMedialAxisAngle识别中轴点的最小夹角，角度制。
meshQualityControls.nSmoothScale / errorReduction质量检查失败后的位移平滑次数与缩减因子，用于调整网格修正过程。
writeFlags调试输出列表：scalarLevels 输出细化级别，layerSets 输出层网格集合，layerFields 输出层覆盖相关字段；大算例不必长期全部开启。

示例 1 · 基本配置

snappyHexMesh 包括切割细化、表面贴合和边界层生成三个阶段。运行 foamGetDict snappyHexMeshDict 获取带注释模板，在已建立的背景网格上配置几何和各阶段参数。

参数含义设置方法
castellatedMesh、snap、addLayers分别控制切割细化、贴体和边界层生成先检查切割细化和贴体，再配置边界层
geometry表面及可搜索几何体body.stl { type triSurfaceMesh; name body; }
maxLocalCells、maxGlobalCells局部及全局细化控制限额根据可用内存设置单元数量上限
minRefinementCells停止继续细化的候选单元阈值设为 0 时继续处理剩余细化单元，计算量相应增加
nCellsBetweenLevels相邻细化级别间的过渡层数例如 3
features显式特征文件和细化等级({ file "body.eMesh"; level 2; })
refinementSurfaces表面的最小最大细化等级body { level (2 3); patchInfo { type wall; } }
resolveFeatureAngle区分尖锐表面特征的角度示例为 30，按表面几何特征确定
refinementRegions体积或距离带细化mode inside、outside 或 distance；levels 定义等级
locationInMesh标记需要保留的连通流体区域取目标流体区域内部点，避开边界面
allowFreeStandingZoneFaces是否允许独立区域面与 zone 生成方式匹配
snapControls贴体松弛和迭代nSmoothPatch、tolerance、nSolveIter、nRelaxIter
显式特征贴合explicitFeatureSnap 与 nFeatureSnapIter与 features 中的 eMesh 配合
layers各 patch 的层数"body.*" { nSurfaceLayers 3; }
relativeSizes层厚是否相对外层网格尺寸true 相对尺寸；false 绝对长度
expansionRatio层间厚度增长比例如 1.2
finalLayerThickness、firstLayerThickness、thickness不同的层厚约束按层厚参数关系选取相容组合
minThickness允许保留的最小总层厚指标阈值过大时，局部边界层将被取消
nGrow、nBufferCellsNoExtrude尖角附近的非挤出区域及过渡缓冲控制未生成边界层区域的过渡
featureAngle、slipFeatureAngle层网格遇尖角时的行为按几何特征及边界层覆盖率调整
nLayerIter、nRelaxedIter边界层生成迭代及质量阈值放宽迭代几何有效性满足要求后设置迭代上限
meshQualityControls质量约束通常包含系统 meshQualityDict
mergeTolerance点合并相对容差常用 1e-6，以几何包围盒尺度为基准

示例来源：本站整理，示例 1 · 基本配置的第 1 段配置。以下片段用于说明参数写法，需与本节列出的其余文件配套使用。

OpenFOAM 字典39 行
// 片段：放入对应的 snappyHexMeshDict
geometry
{
    body.stl { type triSurfaceMesh; name body; }
    refineBox
    {
        type searchableBox;
        min (-0.2 -0.2 -0.2);
        max (1.2 0.2 0.2);
    }
}
castellatedMeshControls
{
    maxLocalCells 1000000;
    maxGlobalCells 3000000;
    minRefinementCells 0;
    nCellsBetweenLevels 3;
    features ({ file "body.eMesh"; level 2; });
    refinementSurfaces
    {
        body { level (2 3); patchInfo { type wall; } }
    }
    resolveFeatureAngle 30;
    refinementRegions
    {
        refineBox { mode inside; levels ((1e15 2)); }
    }
    locationInMesh (2 0 0);
    allowFreeStandingZoneFaces true;
}
snapControls
{
    nSmoothPatch 3; tolerance 2.0;
    nSolveIter 30; nRelaxIter 5;
    nFeatureSnapIter 10;
    implicitFeatureSnap false;
    explicitFeatureSnap true;
    multiRegionFeatureSnap false;
}

locationInMesh 中的 (2 0 0) 表示待保留流体区域内的一点，该点须位于背景网格范围内及物体外部。网格生成前应消除 STL 自相交，统一长度单位，并检查背景网格。

案例文件 1 · incompressible/simpleFoam/motorBike

算例问题：motorBike

来流绕过摩托车与骑手组合外形，表面附近形成边界层，后方形成分离尾流。主要结果为压力、速度、阻力及尾流结构；包含伴随设置时，还用于评价表面形状对目标函数的影响。

算例出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/simpleFoam/motorBike。

motorBike 用 snappyHexMesh 把背景网格贴合摩托车表面，并在尾迹与近壁区域增加分辨率。

  • castellatedMesh true、snap true、addLayers true 分别启用切割加密、表面贴合和层网格。
  • motorBike.obj 提供表面；表面 level (5 6) 与 motorBike.eMesh 的 level 6 加密几何和特征边。
  • refinementBox 从 (−1,−0.7,0) 到 (8,0.7,2.5)，其内部使用 level 4，使尾迹附近保持较细网格。
  • locationInMesh (3.0001 3.0001 0.43) 标记要保留的流体连通域。
  • nSurfaceLayers 1、relativeSizes true、finalLayerThickness 0.3 给指定壁面加一层相对厚度网格。

目标 y⁺ 变化时，应联动背景分辨率与层厚；修改几何后重新检查保留点、层覆盖率和质量。

配置出处：OpenCFD OpenFOAM v2512 官方教程 incompressible/simpleFoam/motorBike/system/snappyHexMeshDict（原文件）。

/*--------------------------------*- C++ -*----------------------------------*\
| =========                 |                                                 |
| \\      /  F ield         | OpenFOAM: The Open Source CFD Toolbox           |
|  \\    /   O peration     | Version:  v2512                                 |
|   \\  /    A nd           | Website:  www.openfoam.com                      |
|    \\/     M anipulation  |                                                 |
\*---------------------------------------------------------------------------*/
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      snappyHexMeshDict;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

// Which of the steps to run
castellatedMesh true;
snap            true;
addLayers       true;


// Geometry. Definition of all surfaces. All surfaces are of class
// searchableSurface.
// Surfaces are used
// - to specify refinement for any mesh cell intersecting it
// - to specify refinement for any mesh cell inside/outside/near
// - to 'snap' the mesh boundary to the surface
geometry
{
    motorBike.obj
    {
        type triSurfaceMesh;
        name motorBike;
    }

    refinementBox
    {
        type box;
        min  (-1.0 -0.7 0.0);
        max  ( 8.0  0.7 2.5);
    }
}


// Settings for the castellatedMesh generation.
castellatedMeshControls
{

    // Refinement parameters
    // ~~~~~~~~~~~~~~~~~~~~~

    // If local number of cells is >= maxLocalCells on any processor
    // switches from from refinement followed by balancing
    // (current method) to (weighted) balancing before refinement.
    maxLocalCells 100000;

    // Overall cell limit (approximately). Refinement will stop immediately
    // upon reaching this number so a refinement level might not complete.
    // Note that this is the number of cells before removing the part which
    // is not 'visible' from the keepPoint. The final number of cells might
    // actually be a lot less.
    maxGlobalCells 2000000;

    // The surface refinement loop might spend lots of iterations refining just a
    // few cells. This setting will cause refinement to stop if <= minimumRefine
    // are selected for refinement. Note: it will at least do one iteration
    // (unless the number of cells to refine is 0)
    minRefinementCells 10;

    // Allow a certain level of imbalance during refining
    // (since balancing is quite expensive)
    // Expressed as fraction of perfect balance (= overall number of cells /
    // nProcs). 0=balance always.
    maxLoadUnbalance 0.10;


    // Number of buffer layers between different levels.
    // 1 means normal 2:1 refinement restriction, larger means slower
    // refinement.
    nCellsBetweenLevels 3;


    // Explicit feature edge refinement
    // ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

    // Specifies a level for any cell intersected by its edges.
    // This is a featureEdgeMesh, read from constant/triSurface for now.
    features
    (
        {
            file "motorBike.eMesh";
            level 6;
        }
    );


    // Surface based refinement
    // ~~~~~~~~~~~~~~~~~~~~~~~~

    // Specifies two levels for every surface. The first is the minimum level,
    // every cell intersecting a surface gets refined up to the minimum level.
    // The second level is the maximum level. Cells that 'see' multiple
    // intersections where the intersections make an
    // angle > resolveFeatureAngle get refined up to the maximum level.

    refinementSurfaces
    {
        motorBike
        {
            // Surface-wise min and max refinement level
            level (5 6);

            // Optional specification of patch type (default is wall). No
            // constraint types (cyclic, symmetry) etc. are allowed.
            patchInfo
            {
                type wall;
                inGroups (motorBikeGroup);
            }
        }
    }

    // Resolve sharp angles
    resolveFeatureAngle 30;


    // Region-wise refinement
    // ~~~~~~~~~~~~~~~~~~~~~~

    // Specifies refinement level for cells in relation to a surface. One of
    // three modes
    // - distance. 'levels' specifies per distance to the surface the
    //   wanted refinement level. The distances need to be specified in
    //   descending order.
    // - inside. 'levels' is only one entry and only the level is used. All
    //   cells inside the surface get refined up to the level. The surface
    //   needs to be closed for this to be possible.
    // - outside. Same but cells outside.

    refinementRegions
    {
        refinementBox
        {
            mode inside;
            levels ((1E15 4));
        }
    }


    // Mesh selection
    // ~~~~~~~~~~~~~~

    // After refinement patches get added for all refinementSurfaces and
    // all cells intersecting the surfaces get put into these patches. The
    // section reachable from the locationInMesh is kept.
    // NOTE: This point should never be on a face, always inside a cell, even
    // after refinement.
    locationInMesh (3.0001 3.0001 0.43);


    // Whether any faceZones (as specified in the refinementSurfaces)
    // are only on the boundary of corresponding cellZones or also allow
    // free-standing zone faces. Not used if there are no faceZones.
    allowFreeStandingZoneFaces true;
}


// Settings for the snapping.
snapControls
{
    //- Number of patch smoothing iterations before finding correspondence
    //  to surface
    nSmoothPatch 3;

    //- Relative distance for points to be attracted by surface feature point
    //  or edge. True distance is this factor times local
    //  maximum edge length.
    tolerance 2.0;

    //- Number of mesh displacement relaxation iterations.
    nSolveIter 30;

    //- Maximum number of snapping relaxation iterations. Should stop
    //  before upon reaching a correct mesh.
    nRelaxIter 5;

    // Feature snapping

        //- Number of feature edge snapping iterations.
        //  Leave out altogether to disable.
        nFeatureSnapIter 10;

        //- Detect (geometric only) features by sampling the surface
        //  (default=false).
        implicitFeatureSnap false;

        //- Use castellatedMeshControls::features (default = true)
        explicitFeatureSnap true;

        //- Detect points on multiple surfaces (only for explicitFeatureSnap)
        multiRegionFeatureSnap false;
}


// Settings for the layer addition.
addLayersControls
{
    // Are the thickness parameters below relative to the undistorted
    // size of the refined cell outside layer (true) or absolute sizes (false).
    relativeSizes true;

    // Per final patch (so not geometry!) the layer information
    layers
    {
        "(lowerWall|motorBike).*"
        {
            nSurfaceLayers 1;
        }
    }

    // Expansion factor for layer mesh
    expansionRatio 1.0;

    // Wanted thickness of final added cell layer. If multiple layers
    // is the thickness of the layer furthest away from the wall.
    // Relative to undistorted size of cell outside layer.
    // See relativeSizes parameter.
    finalLayerThickness 0.3;

    // Minimum thickness of cell layer. If for any reason layer
    // cannot be above minThickness do not add layer.
    // Relative to undistorted size of cell outside layer.
    minThickness 0.1;

    // If points get not extruded do nGrow layers of connected faces that are
    // also not grown. This helps convergence of the layer addition process
    // close to features.
    // Note: changed(corrected) w.r.t 1.7.x! (didn't do anything in 1.7.x)
    nGrow 0;

    // Advanced settings

    // When not to extrude surface. 0 is flat surface, 90 is when two faces
    // are perpendicular
    featureAngle 60;

    // At non-patched sides allow mesh to slip if extrusion direction makes
    // angle larger than slipFeatureAngle.
    slipFeatureAngle 30;

    // Maximum number of snapping relaxation iterations. Should stop
    // before upon reaching a correct mesh.
    nRelaxIter 3;

    // Number of smoothing iterations of surface normals
    nSmoothSurfaceNormals 1;

    // Number of smoothing iterations of interior mesh movement direction
    nSmoothNormals 3;

    // Smooth layer thickness over surface patches
    nSmoothThickness 10;

    // Stop layer growth on highly warped cells
    maxFaceThicknessRatio 0.5;

    // Reduce layer growth where ratio thickness to medial
    // distance is large
    maxThicknessToMedialRatio 0.3;

    // Angle used to pick up medial axis points
    // Note: changed(corrected) w.r.t 1.7.x! 90 degrees corresponds to 130
    // in 1.7.x.
    minMedialAxisAngle 90;


    // Create buffer region for new layer terminations
    nBufferCellsNoExtrude 0;


    // Overall max number of layer addition iterations. The mesher will exit
    // if it reaches this number of iterations; possibly with an illegal
    // mesh.
    nLayerIter 50;
}


// Generic mesh quality settings. At any undoable phase these determine
// where to undo.
meshQualityControls
{
    #include "meshQualityDict"


    // Advanced

    //- Number of error distribution iterations
    nSmoothScale 4;
    //- Amount to scale back displacement at error points
    errorReduction 0.75;
}


// Advanced

// Write flags
writeFlags
(
    scalarLevels
    layerSets
    layerFields     // write volScalarField for layer coverage
);


// Merge tolerance. Is fraction of overall bounding box of initial mesh.
// Note: the write tolerance needs to be higher than this.
mergeTolerance 1e-6;


// ************************************************************************* //
案例文件 2 · mesh/snappyHexMesh/faceZoneRegions

算例问题：faceZoneRegions

根据表面区域生成网格，并建立对应的 faceZone 或 cellZone，供后续区域选择和接口处理使用。重点是几何区域与网格区域名称的对应，以及各区域的连通关系。

算例出处：OpenCFD OpenFOAM v2512 官方教程 mesh/snappyHexMesh/faceZoneRegions。

这个网格示例演示表面区域命名与 faceZone/cellZone 的生成，便于后续把旋转区与固定区分开。

  • 开头 #includeEtc 引入 snappyHexMesh 的公共默认配置，本地条目作具体覆盖。
  • castellatedMesh on、snap on、addLayers off 表示生成并贴合网格，本次不长层。
  • fixed.obj/regions 将原始区域映射为 slipWall、outlet、inlet，同时可以指定各区加密级别。
  • rotatingZone 的 cellZoneInside inside 选取内部单元，faceZoneNaming region 按区域命名相关面区。
  • strictRegionSnap true 强调贴合时的区域对应，locationInMesh 决定保留连通域。

更换表面文件时逐项对应 region 名称；区域正确后再设置旋转或耦合边界。

案例文件 3 · mesh/snappyHexMesh/gap_detection

算例问题：gap_detection

在含狭缝或相近表面的几何中生成网格，利用间隙检测控制局部单元保留与细化。该示例关注窄间隙能否被网格正确表示，以及局部质量和连通性。

算例出处：OpenCFD OpenFOAM v2512 官方教程 mesh/snappyHexMesh/gap_detection。

gap_detection 主要检查窄间隙加密，配置只执行切割加密阶段。

  • castellatedMesh true、snap false、addLayers false 将测试集中在间隙识别。
  • mech_test.obj 提供几何；普通表面级别 (0 0)，间隙细化另由 gapLevel (4 0 10) 控制。
  • gapMode outside 指定间隙检测所考虑的一侧，nCellsBetweenLevels 1 使级别过渡较紧凑。
  • locationInMesh (-100 -5 -300) 选择需要保留的流体连通区域；maxGlobalCells 2000000 限制规模。

细小间隙可能迅速增加单元数，先检查间隙内实际网格层数，再调整 gapLevel 和总体单元上限。

// Which of the steps to run
castellatedMesh true;
snap            false;
addLayers       false;


// Geometry. Definition of all surfaces. All surfaces are of class
// searchableSurface.
// Surfaces are used
// - to specify refinement for any mesh cell intersecting it
// - to specify refinement for any mesh cell inside/outside/near
// - to 'snap' the mesh boundary to the surface
geometry
{
    mech_test.obj
    {
        type triSurfaceMesh;
    }
    all
    {
        type box;
        min  (-1000 -1000 -1000);
        max  (1000 1000 1000);
    }
}


// Settings for the castellatedMesh generation.
castellatedMeshControls
{

    // Refinement parameters
    // ~~~~~~~~~~~~~~~~~~~~~

    // If local number of cells is >= maxLocalCells on any processor
    // switches from from refinement followed by balancing
    // (current method) to (weighted) balancing before refinement.
    maxLocalCells 100000;

    // Overall cell limit (approximately). Refinement will stop immediately
    // upon reaching this number so a refinement level might not complete.
    // Note that this is the number of cells before removing the part which
    // is not 'visible' from the keepPoint. The final number of cells might
    // actually be a lot less.
    maxGlobalCells 2000000;

    // The surface refinement loop might spend lots of iterations refining just a
    // few cells. This setting will cause refinement to stop if <= minimumRefine
    // are selected for refinement. Note: it will at least do one iteration
    // (unless the number of cells to refine is 0)
    minRefinementCells 0;

    // Number of buffer layers between different levels.
    // 1 means normal 2:1 refinement restriction, larger means slower
    // refinement.
    nCellsBetweenLevels 1;


    // Explicit feature edge refinement
    // ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

    // Specifies a level for any cell intersected by its edges.
    // This is a featureEdgeMesh, read from constant/triSurface for now.
    features
    (
    );


    // Surface based refinement
    // ~~~~~~~~~~~~~~~~~~~~~~~~

    // Specifies two levels for every surface. The first is the minimum level,
    // every cell intersecting a surface gets refined up to the minimum level.
    // The second level is the maximum level. Cells that 'see' multiple
    // intersections where the intersections make an
    // angle > resolveFeatureAngle get refined up to the maximum level.

    refinementSurfaces
    {
        mech_test.obj
        {
            // Surface-wise min and max refinement level
            level (0 0);
        }
    }

    // Resolve sharp angles
    resolveFeatureAngle 60;


    // Region-wise refinement
    // ~~~~~~~~~~~~~~~~~~~~~~

    // Specifies refinement level for cells in relation to a surface. One of
    // three modes
    // - distance. 'levels' specifies per distance to the surface the
    //   wanted refinement level. The distances need to be specified in
    //   descending order.
    // - inside. 'levels' is only one entry and only the level is used. All
    //   cells inside the surface get refined up to the level. The surface
    //   needs to be closed for this to be possible.
    // - outside. Same but cells outside.

    refinementRegions
    {
        all
        {
            mode        inside;

            // Dummy base level
            levels      ((10000 0));

            // If cells
            // - have level 0..9
            // - and are in a gap < 3 cell sizes across
            // - with the gap on the inside ('inside'), outside ('outside')
            //   or both ('mixed') of the surface
            // refine them
            gapLevel    (4 0 10);
            gapMode     outside;
        }
    }


    // Mesh selection
    // ~~~~~~~~~~~~~~

    // After refinement patches get added for all refinementSurfaces and
    // all cells intersecting the surfaces get put into these patches. The
    // section reachable from the locationInMesh is kept.
    // NOTE: This point should never be on a face, always inside a cell, even
    // after refinement.
    locationInMesh (-100 -5 -300);


    // Whether any faceZones (as specified in the refinementSurfaces)
    // are only on the boundary of corresponding cellZones or also allow
    // free-standing zone faces. Not used if there are no faceZones.
    allowFreeStandingZoneFaces false;
}


// Settings for the snapping.
snapControls
{
    //- Number of patch smoothing iterations before finding correspondence
    //  to surface
    nSmoothPatch 3;

    //- Relative distance for points to be attracted by surface feature point
    //  or edge. True distance is this factor times local
    //  maximum edge length.
    tolerance 2.0;

    //- Number of mesh displacement relaxation iterations.
    nSolveIter 30;

    //- Maximum number of snapping relaxation iterations. Should stop
    //  before upon reaching a correct mesh.
    nRelaxIter 5;


    // Feature snapping

        //- Number of feature edge snapping iterations.
        //  Leave out altogether to disable.
        nFeatureSnapIter 10;

        //- Detect (geometric) features by sampling the surface (default=false)
        implicitFeatureSnap true;

        //- Use castellatedMeshControls::features (default = true)
        explicitFeatureSnap false;
}


// Settings for the layer addition.
addLayersControls
{
    // Are the thickness parameters below relative to the undistorted
    // size of the refined cell outside layer (true) or absolute sizes (false).
    relativeSizes true;

    // Per final patch (so not geometry!) the layer information
    layers
    {
    }

    // Expansion factor for layer mesh
    expansionRatio 1.0;

    // Wanted thickness of final added cell layer. If multiple layers
    // is the thickness of the layer furthest away from the wall.
    // Relative to undistorted size of cell outside layer.
    // is the thickness of the layer furthest away from the wall.
    // See relativeSizes parameter.
    finalLayerThickness 0.5;

    // Minimum thickness of cell layer. If for any reason layer
    // cannot be above minThickness do not add layer.
    // Relative to undistorted size of cell outside layer.
    // See relativeSizes parameter.
    minThickness 0.25;

    // If points get not extruded do nGrow layers of connected faces that are
    // also not grown. This helps convergence of the layer addition process
    // close to features.
    // Note: changed(corrected) w.r.t 1.7.x! (didn't do anything in 1.7.x)
    nGrow 0;


    // Advanced settings

    // When not to extrude surface. 0 is flat surface, 90 is when two faces
    // are perpendicular
    featureAngle 60;

    // Maximum number of snapping relaxation iterations. Should stop
    // before upon reaching a correct mesh.
    nRelaxIter 5;

    // Number of smoothing iterations of surface normals
    nSmoothSurfaceNormals 1;

    // Number of smoothing iterations of interior mesh movement direction
    nSmoothNormals 3;

    // Smooth layer thickness over surface patches
    nSmoothThickness 10;

    // Stop layer growth on highly warped cells
    maxFaceThicknessRatio 0.5;

    // Reduce layer growth where ratio thickness to medial
    // distance is large
    maxThicknessToMedialRatio 0.3;

    // Angle used to pick up medial axis points
    // Note: changed(corrected) w.r.t 16x! 90 degrees corresponds to 130 in 16x.
    minMedialAxisAngle 90;

    // Create buffer region for new layer terminations
    nBufferCellsNoExtrude 0;


    // Overall max number of layer addition iterations. The mesher will exit
    // if it reaches this number of iterations; possibly with an illegal
    // mesh.
    nLayerIter 50;
}
