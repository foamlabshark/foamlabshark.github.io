kinematicCloudProperties

运动学颗粒云的离散相控制文件，包含载体耦合、积分格式、注入方式、阻力与碰撞等子模型。

简要介绍

运动学颗粒云通过这个字典定义注入、运动积分和阻力、碰撞等子模型，并指定与载体的耦合方式。它决定颗粒从哪里进入、怎样受力以及如何向流体反馈动量。

位置：constant/kinematicCloudProperties

参数说明

条目含义
solution颗粒云的求解控制，包含稳态/瞬态、载体耦合、源项与时间积分等。
active是否启用当前模型实例或操作。
coupled是否向连续相反馈颗粒源项。
transient选择瞬态或稳态颗粒云控制方式，必须与求解器匹配。
rho密度或密度场引用；是否为量纲标量、常量或场名由模型定义。
constantProperties单个颗粒或材料的基本属性，例如密度、温度和热容；具体键由云类型决定。
subModels颗粒云注入、力、传热、碰撞和相变等子模型集合。
particleForces作用于颗粒的力模型列表，例如阻力和重力，实际可选模型由云类型决定。
injectionModels注入时间、位置、流量与粒径分布等设置；需要同时满足总注入质量与统计分辨率要求。
patchInteractionModel颗粒与边界接触时的反弹、粘附或逸出处理。
surfaceFilmModel表面液膜模型选择，需与液膜区域和主流体耦合条件配套。
type运行时选择的模型或操作类型，同一个关键字在不同子字典中具有不同注册表。
cloudFunctions按自定义对象名添加颗粒统计。GName 指定热或辐射模型引用的辐射场。
mu通常表示动力黏度，也可能在特定模型中表示其他系数；必须结合量纲和源码语境确认。

模型选择与嵌套参数

按 solution、constantProperties、subModels 和注入器子字典分别设置求解、物性、物理模型与注入参数。

物种和固体组分按计算对象命名，例如 H2O、C7H16、CH4、CO2、H2、ash、C。U、h、Yi 表示交换量，model1 为可自定的实例名。

参数说明
solution.active / coupled / transient启用颗粒云、开启双向耦合、选择瞬态跟踪。coupled false 仍可跟踪颗粒，但不把交换源项反馈给载体。
solution.cellValueSourceCorrection / maxCo是否在跟踪过程中修正单元内载体源项，以及限制颗粒跟踪子步的 Courant 数。
solution.sourceTerms.schemes按 U、h、Yi 等交换量选择源项处理方案与松弛参数；这些字段键必须对应所用云类型。
solution.interpolationSchemes载体字段到颗粒位置的插值方式，按云模型选用 rho、U、T、p、thermo:mu、Cp、kappa、G 等字段；G 为辐射入射量。
solution.integrationSchemes按 U、T 等颗粒变量选择 Euler、analytical 等时间积分方案；选择取决于变量方程。
constantProperties.rho0 / T0 / Cp0初始密度、温度与比热容。热物性型云可能随后按组成、压力和温度更新这些量。
constantProperties.constantVolume指定相应颗粒模型是否维持体积，需与其质量与密度更新方式配套。
constantProperties.epsilon0 / f0颗粒辐射发射率与散射因子；只在支持相应辐射模型的云中使用。
subModels.injectionModels.<名称>每个注入器自己的 type 与系数字典；model1 是自定义注入器名。多个注入器可并列。
SOI / duration / massTotal注入器内的开始时刻、持续时间与总注入质量；某些从已有液滴记录导入的模型会重新计算 massTotal。
parcelBasisType / nParticle用 mass、number 或 fixed 等方式确定每个计算包代表的真实颗粒数；fixed 模式明确给出 nParticle。
positionsFile / U0 / patch按注入器填写几何和初始速度：manualInjection 使用位置文件，patchInjection 使用注入边界。
parcelsPerSecond / flowRateProfile计算包抽样率与注入流量的时间分布。抽样率控制统计分辨率，不等于真实粒子数流率。
sizeDistribution注入粒径分布子字典：type 选择模型。RosinRammler 使用 RosinRammlerDistribution，uniform 使用 uniformDistribution。
RosinRammlerDistribution.minValue / maxValue / lambda / n粒径上下限、尺度参数与形状指数。长度与网格采用相同单位；使用米制时，将微米数值乘以 1e-6。
dispersionModel / stochasticCollisionModel选择湍流弥散和随机碰撞模型，none 关闭相应过程。使用 collisionModel 的云按其碰撞模型配置。
standardWallInteractionCoeffs.type / e / mu标准壁面相互作用的处理方式、恢复系数与摩擦系数；rebound、stick、escape 的含义不同。
heatTransferModel / RanzMarshallCoeffs.BirdCorrectionRanzMarshall 换热模型的 Bird 修正开关，用于考虑传质对换热的影响。
compositionModel / phaseChangeModel选择颗粒组成与相变模型，在 singlePhaseMixtureCoeffs 或 singleMixtureFractionCoeffs 的 phases 中填写组分。
liquidEvaporationCoeffs / liquidEvaporationBoilCoeffs相变模型的 activeLiquids 指定可蒸发液体；enthalpyTransfer 选择焓交换的计算方式。

模型参数

参数说明
muc / thermo:mu载体动力黏度字段名，填写求解器提供的字段名称。
kinematicSurfaceFilmCoeffs运动学颗粒云与表面液膜相互作用模型的系数字典。
UrMax碰撞模型的相对速度上限。

配置示例

配套案例文件

下载配置后，可从案例目录取得配套网格、初始场和 include 文件。

案例文件 1 · lagrangian/kinematicParcelFoam/drippingChair

drippingChair 将液膜与离散液滴连接起来：液滴在空间中运动，与液膜区域相遇后可转入膜内。

  • active true、transient yes 启用非定常颗粒跟踪；coupled yes 让颗粒对连续相产生反作用，动量源项采用 semiImplicit 1。
  • maxCo 0.3 限制颗粒跟踪子步相对单元尺度的移动程度；流体时间步仍由运行设置控制。
  • rho0 1000 kg/m³ 给出水滴密度。sphereDrag 与 gravity 分别考虑球形颗粒阻力和重力。
  • injectionModels 为空，当前云没有独立的常规喷射器。与液膜的颗粒交换由 kinematicSurfaceFilm 及液膜端模型配合处理。
  • interactionType absorb 表示液滴撞到适用液膜区域后被吸收；其他壁面使用 standardWallInteraction 的 rebound 设置。

可先降低 maxCo 比较液滴撞击位置，再改变液膜侧的脱落设置观察滴落频率。若加入独立喷嘴，则需要补充注入模型、流量、粒径和速度，并检查两种液滴来源的质量收支。

案例文件 2 · lagrangian/kinematicParcelFoam/windshield

windshield 从入口释放液滴，展示液滴与挡风玻璃表面液膜的相互作用。

  • coupled no 采用单向耦合，颗粒不会把动量反馈给连续相。本文件中的 sphereDrag 和 gravity 行均被注释，当前受力列表为空，适合观察按给定初速度到达壁面的几何过程。
  • patchInjection 从 inlet 注入，SOI 0、duration 1000 表示从零时刻开始、持续 1000 s；massTotal 1 kg 对应整个注入时段的总质量。
  • parcelsPerSecond 100 控制每秒注入的计算包数量；U0 (0 0 -1) 给出沿负 z 方向的 1 m/s 初速度。
  • Rosin–Rammler 分布的直径范围为 1–3 mm，lambda 7.5e-05、n 0.5 决定被该范围截取的分布形状。粒径统计应结合上下限理解。
  • kinematicSurfaceFilm 的 absorb 把落在液膜区域的液滴转入膜内；普通壁面使用反弹模型。

加入空气阻力或重力时，取消相应力项的注释，再比较落点与撞击速度。改变采样包数量时保持总质量和粒径分布一致，可以观察随机抽样误差。

案例文件 3 · lagrangian/uncoupledKinematicParcelDyMFoam/rotor2DAMI

rotor2DAMI 用旋转网格与 AMI 接口测试颗粒跨区域跟踪。注入发生在一个很短的时间窗内，便于观察一批颗粒穿过旋转区域。

  • coupled false 采用单向耦合，particleForces 中的阻力和重力被注释；初始颗粒速度设为 U0 (0.1 0 0) m/s。
  • patchInjection 在 inlet 注入，SOI 0、duration 0.00001 s 与 parcelsPerSecond 20000000 对应名义约 200 个计算包。
  • parcelBasisType fixed、nParticle 1 指定每个计算包代表一个真实颗粒，粒径为固定 50 μm。统计权重在这里由 nParticle 决定。
  • maxCo 0.3 控制颗粒跟踪子步。AMI 传递与旋转网格运动还依赖配套网格和动网格文件。
  • 文件末尾给出 standardWallInteraction：e 0.9 控制法向反弹，mu 0.09 控制切向衰减。整理自己的配置时，将文件中重复出现的 patchInteractionModel 合并为一次明确选择。

改变旋转速度后，可追踪同一批颗粒的穿越位置与数量。提高 parcelsPerSecond 会增加这次短脉冲中的样本数；延长 duration 则把单批穿越实验扩展为连续注入。

    {
        U               Euler;
    }

{

    rho0            1000;
    constantVolume  true;

}

subModels
{
    particleForces
    {
        //sphereDrag;
        //gravity;
    }

    injectionModels
    {
         model1
        {
            type            patchInjection;
            parcelBasisType fixed;

            {
                type uniform;

常见问题

现象检查方法
模型或类型名称未识别：Unknown model / Unknown type核对模型名、求解器所构建的模型类别和 libs；同名模型可能属于不同注册表。
量纲不一致或压力基准错误按场的 dimensions 和模型要求填写物性与压力单位：运动学压力为 p/ρ，热力学压力以 Pa 表示。
计算收敛但物理结果不合理用质量、能量、相分数范围和极限工况检查模型，同时比较流量、压降等目标量与参考数据。
