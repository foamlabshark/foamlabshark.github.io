OpenFOAM v2512

foamyHexMeshDict

foamyHexMesh 的体网格、尺寸控制与网格优化参数。

简要介绍

这个字典组织 foamyHexMesh 的表面几何、单元尺寸、方向控制和优化设置。它适合以六面体为主的自动贴体建网流程，各控制项共同决定几何附近和内部区域的单元分布。

位置：system/foamyHexMeshDict

参数说明

条目含义
type运行时选择的模型或操作类型，同一个关键字在不同子字典中具有不同注册表。

模型参数

尺寸系数以局部目标单元尺寸为基准；具体含义见各参数说明。

参数说明
geometry搜索表面与几何体，按 triSurfaceMesh、searchableBox 等类型填写 name、min、max 等参数。
surfaceConformation.geometryToConformTo / additionalFeatures指定要贴合的几何及附加特征。featureMethod 与 extendedFeatureEdgeMesh 配合选择特征边来源。
motionControl控制网格生成时的点运动、尺寸与松弛。
surfaceCellSizeFunction / cellSizeFunction表面和空间尺寸分布的模型选择；uniformValueCoeffs、uniformCoeffs 等只在对应模型选中时读取。
priority / defaultPriority多个尺寸或形状控制区域重叠时的优先级。
surfaceConformation.pointPairDistanceCoeff / mixedFeaturePointPPDistanceCoeff表面与混合特征点附近的成对点间距比例。
surfaceConformation.featurePointExclusionDistanceCoeff / featureEdgeExclusionDistanceCoeff特征点、特征边附近的排斥距离系数，防止过密或相互冲突的辅助点。
surfaceConformation.surfaceSearchDistanceCoeff / maxSurfaceProtrusionCoeff表面搜索距离与允许的表面突出量。
surfaceConformation.maxQuadAngle / surfaceConformationRebuildFrequency凹特征边处允许的最大象限角，以及表面贴合重建频率；前者超过限制时增加辅助分隔线。
surfaceConformation.featurePointControls.specialiseFeaturePoints / guardFeaturePoints特征点专门处理与保护点生成开关。
surfaceConformation.featurePointControls.snapFeaturePoints / edgeAiming / circulateEdges贴合特征点、朝向特征边与遍历相邻边的处理开关。guardFeaturePoints 关闭时才读取 snapFeaturePoints。
surfaceConformation.conformationControls.surfacePtExclusionDistanceCoeff粗表面贴合时的点排斥距离。
surfaceConformation.conformationControls.edgeSearchDistCoeff / surfacePtReplaceDistCoeff特征边搜索与替换已有表面点的距离系数。
surfaceConformation.conformationControls.maxIterations / iterationToInitialHitRatioLimit表面贴合迭代上限及相对初始命中数量的停止限制。
motionControl.defaultCellSize / minimumCellSizeCoeff默认尺寸与最小尺寸比例；后者乘默认尺寸得到最小网格尺度。
motionControl.alignmentAcceptanceAngle / maxLoadUnbalance网格方向对齐的接受角与并行负载不均衡限制。
motionControl.pointInsertionCriteria用 cellCentreDistCoeff、faceAreaRatioCoeff、acceptanceAngle 控制新点插入。
motionControl.pointRemovalCriteria.cellCentreDistCoeff删除过近网格点的距离判据。
motionControl.objOutput / timeChecks / printVertexInfo几何调试输出、计时与顶点信息开关，不直接提高网格质量。
polyMeshFiltering.filterEdges / filterFaces最终多面体网格的边、面过滤；filterFaces 打开时会同时打开边过滤。
polyMeshFiltering.meshQualityControls过滤后的网格质量限制；writeTetDualMesh、writeCellShapeControlMesh、writeBackgroundMeshDecomposition 为辅助网格输出。
initialPoints.initialPointsMethod初始点生成方式。autoDensityCoeffs 控制 maxSizeRatio、surfaceSampleResolution 等；pointFileCoeffs 指定 pointFile 及 insideOutsideCheck。
initialPoints 的 randomiseInitialGrid / randomPerturbationCoeff初始点随机扰动及其幅度，放在所选初始化方法的配置作用域内。
backgroundMeshDecomposition.spanScale / maxCellWeightCoeff并行背景分解的包围区域尺度与单元权重限制。

案例文件 1 · incompressible/porousSimpleFoam/straightDuctImplicit

straightDuctImplicit 使用 foamyHexMesh 在管道几何周围生成多面体网格，公共配置与本算例几何分别通过 include 读入。

  • locationInMesh (-0.078 0.02 0) 选择保留的内部区域，该点应位于管道流体域。
  • defaultCellSize 0.0035 给出默认单元尺度 3.5 mm，局部尺度由 shapeControlFunctions 补充。
  • 特征边来自 boundaryAndFaceZones.extendedFeatureEdgeMesh，edgeAiming 等选项使生成网格适应几何棱边。
  • maxRefinementIterations 0、maxSmoothingIterations 100 配置细化与平滑阶段；公共 include 中仍提供其他控制项。
  • filterEdges false、filterFaces off 关闭最后的边、面过滤，writeTetDualMesh true 输出相应中间网格。

更换管道尺寸时同步修改内部点与单元尺度，并检查入口、出口和壁面是否被正确识别。

案例文件 2 · mesh/foamyHexMesh/mixerVessel

mixerVessel 的几何含有叶片和容器壁，需要空间变化的网格尺度与特征贴合。

  • defaultCellSize 0.006 设置默认尺度 6 mm，shapeControlFunctions 给出叶片等部位的局部要求。
  • 初始 autoDensity 布点中 minLevels 2、sampleResolution 5 控制几何采样与密度估计。
  • locationInMesh (0 0.1 1) 指定流体域内点，maxIterations 15 限制边界贴合迭代次数。
  • maxRefinementIterations 1、maxSmoothingIterations 100 允许一次细化和较充分的平滑；filterEdges on 清理局部短边。
  • 开启 writeBackgroundMeshDecomposition 与 writeCellShapeControlMesh 输出有助于查看网格尺寸如何从几何需求过渡到实际单元。

叶片间隙分辨率不足时先修改局部尺度函数，再检查狭缝中的单元数和网格质量。

案例文件 3 · mesh/foamyHexMesh/blob

blob 算例用 STL 表面定义几何，再通过 foamyHexMesh 生成贴合网格。

  • blob.stl 作为 triSurfaceMesh 读入，refinementBox 还定义了一个可用于局部控制的空间盒。
  • locationInMesh (0.1 0.1 0.2) 指定要保留的区域。
  • defaultCellSize 0.1 给出基准尺度，blob 的 searchableSurfaceControl 以 priority 1、mode bothSides 控制表面两侧。
  • cellSizeFunction uniform 与 surfaceCellSizeCoeff 1 使用均匀的表面尺度关系；featureMethod none 适合这种平滑几何演示。
  • maxSmoothingIterations 100 控制平滑上限，质量标准由 meshQualityDict 提供。

几何缩放后同步调整默认尺度和内部点，再检查曲率较大位置的表面分辨率。

// Include defaults parameters from master dictionary
#includeEtc "caseDicts/foamyHexMeshDict"

geometry
{
    blob.stl
    {
        name blob;
        type triSurfaceMesh;
    }

    refinementBox
    {
        type box;
        min  (-0.2  -0.6 -0.2);
        max  ( 0.4   0.2  0.35);
    }
}


backgroundMeshDecomposition
{
    minLevels           0;
    sampleResolution    4;
    spanScale           20;
    maxCellWeightCoeff  20;
}


initialPoints
{
    initialPointsMethod         autoDensity;
    // initialPointsMethod     pointFile;

    autoDensityCoeffs
    {
        minLevels               0;
        maxSizeRatio            5.0;
        sampleResolution        5;
        surfaceSampleResolution 5;
    }

    pointFileCoeffs
    {
        pointFile               "<constant>/internalDelaunayVertices";
    }
}


surfaceConformation
{
    locationInMesh              (0.1 0.1 0.2);

    featurePointControls
    {
        specialiseFeaturePoints off;
        edgeAiming              off;
        guardFeaturePoints      off;
        snapFeaturePoints       off;
        circulateEdges          off;

    geometryToConformTo
    {
        blob
        {
            featureMethod       none;
        }
    }
}


motionControl
{

    minimumCellSizeCoeff        0;

    maxSmoothingIterations      100;

    maxRefinementIterations     0;

    shapeControlFunctions
    {
        blob

            type                    searchableSurfaceControl;
            priority                1;
            mode                    bothSides;

            surfaceCellSizeFunction uniformValue;
            uniformValueCoeffs
            {
                surfaceCellSizeCoeff     1;
            }

            uniformCoeffs
            {}
        }

}

常见问题

现象检查方法
边界名称与字段不一致修改拓扑后，更新 constant/polyMesh/boundary 和所有 0/ 场文件中的边界配置。
单位或坐标方向错误比较几何包围盒与预期物理尺寸；检查 scale、挤出法向和旋转轴。
网格生成成功但质量不足运行 checkMesh -allTopology -allGeometry，再评估所选离散格式对非正交和扭曲的容忍度。
