新宿街区风环境：真实建筑群与测点对比

正在打开最新内容…

以 AIJ 新宿街区的真实建筑群和风速测量为依据，计算建筑绕流、街谷加速与行人高度的风速分布。

工程场景：高层建筑如何改变街道上的风

高层建筑迎风面的气流受阻后，一部分向两侧绕行，一部分沿立面向下运动。下洗气流进入近地面区域，与道路、低层建筑和裙房共同形成局部加速区。建筑背风侧则可能形成回流和低速区。两座建筑之间的通道宽度、相对位置及来流方向发生变化，都可能改变行人活动区域的风环境。

这类计算服务于建筑布局、入口和广场设计，也用于分析自然通风与污染物输运。工程判断需要定位强风区出现在哪里、对哪一类来流最敏感，以及方案调整能否降低目标区域的风速。单独计算一座规则方柱，无法覆盖真实街区中高低建筑相互遮挡、街道转折和地形高差的影响。

本案例采用日本建筑学会 AIJ Case F。公开 STL 表示新宿副中心在 1978 年 11 月的建筑构型，配套数据包括风洞来流剖面、风洞测点和对应时期的现场观测。保留这一历史构型，才能将计算值与同一组测量比较；补入今天的新建筑后，研究对象已经改变。

首先完成北风工况，在已知测点比较无量纲风速；再改变风向，辨认建筑转角、街谷和背风区的响应。完成基准对比后，可以在副本中调整某一处建筑或挡风设施，比较修改前后的局部风速。

几何及测量数据由 Tominaga、Kikumoto 和 Okaze 整理发布，采用 CC BY 4.0 许可。原始数据集与各文件下载。图中建筑形状来自该数据集，本站仅转换尺度并重新绘图。

先把模型尺度和测点位置统一

新发布的 BD_caseF.stl 使用风洞尺度，缩尺比为 1∶800，单位已经是米。本节转换为实体尺度：所有几何坐标和风洞测点坐标乘以 800。入口采用同数据集 LF_CaseF.xls 的 Inflow 表所列无量纲剖面，并选择实体高度 500 m 处的参考风速为 10 m/s。

文件 包含内容 本节处理
BD_caseF.stl 建筑与地形，风洞尺度 坐标乘 800；原文件保留
AF_caseF.csv 来流高度、平均风速、流向速度脉动均方根 保留原始测量用于复核
LF_CaseF.xls 的 Inflow 表 完整归一化入口剖面 使用实体高度；速度比乘 10，湍动能比乘 100
RS-WT_caseF.csv 风洞测点、风向和无量纲风速 三个坐标分量乘 800
RS-FO_caseF.csv 实体尺度现场观测 保持原坐标，单独比较

原 STL 包围盒约为 x、y 方向各 1.8125 m，高度 0.28125 m。转换后模型范围约 1450 m×1450 m，最大高度 225 m。这里是原文件的几何范围，外部流体域还需向上游、下游和侧面扩展。

资料包提供 prepare_city.py。它检查原始文件校验值，转换 STL 和测点，并输出北风工况测点表、入口剖面以及几何检查信息：

Bash / 终端2 行
python3 prepare_city.py
surfaceCheck geometry/shinjuku-metres.stl

第一条命令完成尺度转换，第二条检查三角表面。原始城市 STL 含有开放边缘和地形连接，不能仅凭文件能够显示就直接认为流体域已封闭。应在网格软件中检查建筑底面与地形的连接，修复重叠面和局部缝隙，再导出用于网格划分的表面。

原模型为表示地下空间而整体抬高了相当于实体 10 m 的高度。风洞测点 z=0.02375 m，转换后为 19 m，对应离原地面约 9 m。不能把它直接放在实体 z=9 m 的位置，否则采样高度会差 10 m。保留原 STL 时，全域坐标以风洞底板为零点；入口剖面也沿用底板高度，不将测点换算地面相对高度时所减的 10 m 再扣到入口上。若平移几何，必须同步平移测点和入口表的高度坐标。

流动模型与入口风剖面

采用中性、等温、不可压缩 RANS 模型，先用 simpleFoam 和标准 kEpsilon 获得平均风场。平均动量方程为

U‾⋅∇U‾=−∇pk+∇⋅[ν∇U‾−u′u′‾],∇⋅U‾=0. \overline{\mathbf U}\cdot\nabla\overline{\mathbf U} =-\nabla p_k+\nabla\cdot\left[\nu\nabla\overline{\mathbf U} -\overline{\mathbf u'\mathbf u'}\right], \qquad \nabla\cdot\overline{\mathbf U}=0. U⋅∇U=−∇pk​+∇⋅[ν∇U−u′u′],∇⋅U=0.

pk=p/ρp_k=p/\rhopk​=p/ρ 为运动学压力，−u′u′‾-\overline{\mathbf u'\mathbf u'}−u′u′ 表示速度脉动对平均动量输运的影响。湍流模型将这个未知应力与平均速度梯度联系起来。建筑背风回流、屋顶剪切层和窄通道中的预测偏差，应结合模型对分离和湍流混合的描述来分析。

入口速度随高度增大。本节按 Inflow 表插值建立剖面。例如，在选定的参考风速下，实体高度 20 m 对应 4.2 m/s，80 m 对应 6.2 m/s，400 m 对应 9.4 m/s。不能把所有入口单元都设成 10 m/s，否则近地面的来流动量会明显偏大。

Inflow 表同时给出归一化湍动能，本节直接读取。若改用只提供流向速度脉动 urmsu_{\rm rms}urms​ 的测量文件，需要先说明湍动能的估算方式。常用的各向同性近似及耗散率关系为：

k(z)=32urms(z)2,ε(z)=Cμ3/4k(z)3/2L(z),Cμ=0.09. k(z)=\frac32u_{\rm rms}(z)^2, \qquad \varepsilon(z)=\frac{C_\mu^{3/4}k(z)^{3/2}}{L(z)},\quad C_\mu=0.09. k(z)=23​urms​(z)2,ε(z)=L(z)Cμ3/4​k(z)3/2​,Cμ​=0.09.

这里的 k 和 ε 分别是湍动能与耗散率。L(z) 是建模输入，决定湍流衰减的尺度；资料包以入口底板为高度零点，取 L=0.41 max(z,0.5) m，并把这一假设与原始测量分开保存。先在去除建筑的空域中计算相同来流，检查剖面沿流向是否保持，再加入建筑。

北风工况的方向

原始平面图中 x 向东、y 向北、z 向上。气象学的“北风”表示风从北方吹来，因此北侧为入口，速度方向为负 y。为减少方向错误，首个算例保持建筑和测点原坐标，仅按该方向建立外部边界。

OpenFOAM 配置流程

1. 建立足够大的外部流体域

以最高建筑高度 H=225 m 作为尺度，入口和侧边界先距建筑群边缘至少 5H，出口距下游边缘至少 15H，顶部距最高建筑至少 5H。对北风，入口在 y 最大的一侧，出口在 y 最小的一侧。随后通过扩大域和比较测点风速，判断边界对结果的影响。

在 snappyHexMeshDict 中将建筑表面、地形表面、测点周围街区和高层建筑尾流设为不同细化区。第一层网格与壁面函数相配，狭窄道路至少需要多层单元跨越通道，避免两侧边界层和中部气流全部落入同一个单元。

2. 让入口字段使用同一套高度数据

准备程序输出 inletProfiles.csv，列出 z、U、k、ε，供映射边界或 codedFixedValue 使用。下面给出 0/U 中的核心写法，完整高度表在资料包中：

foam22 行
north
{
    type            codedFixedValue;
    value           uniform (0 -6.2 0);
    name            measuredNorthWind;
    code
    #{
        const scalar zTab[] = {10,20,35,40,50,60,65,80,100,120,140,160,200,240,280,320,360,400,470,500};
        const scalar uTab[] = {3.2,4.2,4.6,5.0,5.5,5.8,6.0,6.2,6.3,6.5,6.8,7.3,7.7,8.1,8.4,8.9,9.2,9.4,9.6,10};
        vectorField values(patch().size(), vector::zero);
        forAll(values, facei)
        {
            const scalar z = max(patch().Cf()[facei].z(), scalar(0));
            scalar u = z < 10 ? 3.2*z/10 : 10;
            for (label j=0; j<19; ++j)
                if (z>=zTab[j] && z<zTab[j+1])
                    u=uTab[j]+(uTab[j+1]-uTab[j])*(z-zTab[j])/(zTab[j+1]-zTab[j]);
            values[facei]=vector(0,-u,0);
        }
        operator==(values);
    #};
}

表中高度之间按相邻节点线性插值；最低节点以下连接到地面零速度，500 m 以上保持参考风速。最低节点以下的近地面处理应与壁面粗糙度共同检查，避免剖面一进入流体域就发生明显调整。

0/k 和 0/epsilon 应由同一份高度表生成，不能分别套用无关的常数入口。若改用对数律大气边界层入口，则 U、k、ε 和地面粗糙度必须成套更换，并重复空域检查。

3. 设置其余边界与求解控制

位置 速度 压力 湍流量与壁面
南侧出口 inletOutlet fixedValue 0 流出零梯度；回流给与入口一致的物理量
两侧与顶部 symmetryPlane symmetryPlane 几何 patch 同步设置
建筑壁面 noSlip zeroGradient k、ε、nut 使用配套壁面函数
地面 noSlip zeroGradient 使用与入口一致的粗糙壁面处理

地面粗糙度代表未被显式建模的小尺度粗糙元。已作为实体建模的建筑不能再全部折算成同样大的粗糙度重复计入。若用砂粒粗糙壁面函数，还应检查第一层单元高度与粗糙高度的相容性。

先用有界的一阶对流格式获得稳定初场，再转为二阶格式完成结果统计。每次改变格式后继续监控测点速度，避免只比较残差曲线。

Bash / 终端6 行
blockMesh
surfaceFeatureExtract
snappyHexMesh -overwrite
checkMesh -allTopology -allGeometry
decomposePar
mpirun -np 8 simpleFoam -parallel

这组命令从外部背景域生成街区网格并启动并行求解。surfaceFeatureExtract 根据已修复的表面提取建筑转角；原始 STL 转角密集，特征角阈值应结合网格预览选择。流体域内部的 locationInMesh 要位于建筑外，不能落入建筑实体或地下封闭空间。

4. 在实测位置采样

下面是北风测点 1 的速度探针，写入 controlDict 的 functions 中。坐标由原始数据逐项乘以 800 得到。

foam9 行
windProbes
{
    type                probes;
    libs                (sampling);
    fields              (U);
    writeControl        timeStep;
    writeInterval       20;
    probeLocations      ((268.6 364.1 19));
}

268.6 364.1 19 是计算域中的位置，不是“建筑编号 1”。资料包输出所有北风测点坐标；同一平面位置的不同高度应分别保留，不能只按测点编号去重。

结果分析：先比较测点，再解释空间分布

数据集的风速比定义为

Ki=∣U‾i∣U500, K_i=\frac{|\overline{\mathbf U}_i|}{U_{500}}, Ki​=U500​∣Ui​∣​,

分母为相当于实体高度 500 m 的来流参考速度，本节设为 10 m/s。结果对比采用新版 RS-WT_caseF.csv；旧版表格的结果页采用过不同屋顶参考点，不能直接混用旧、新结果页的归一化数值。本文只从旧版 Inflow 页读取以 500 m 为参考高度的入口剖面。

按 (测点编号, x, y, z, 风向) 逐行对齐数据，计算风速比差值与均方根误差。对误差较大的测点，回到三维模型检查测点是否靠近墙面、位于分离区或处在狭窄通道。对比顺序为风洞测量、不同网格计算、现场观测。现场的来流变化和统计方式与稳态计算不同，单独绘图有助于辨认差异来源。

空间分析至少包含三个视图：近地面风速比、沿主街道的竖直截面、高层建筑背风侧的速度矢量。借助截面区分下洗、绕流加速和回流，解释某个测点为何偏高或偏低。

进一步评估全年风舒适性时，还需要当地各风向的风速频率分布，并按指定评价标准累积超越概率。单一北风工况提供的是速度传递关系，年度出现频率需要另行输入。

熊猫说：

城市模型最容易出错的是坐标和高度。本数据集的 STL 是 1∶800 的米制模型，测点还包含相当于实体 10 m 的抬高量。先核对一处建筑高度和一个测点，再批量导入全部几何。
