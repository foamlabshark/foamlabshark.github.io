OPENFOAM · v2512

Ladenburg 喷口的欠膨胀射流

正在打开最新内容…

计算高压气体喷出后形成的欠膨胀射流，分析膨胀扇、激波胞与压力恢复。

工程场景与计算目标

喷管出口压力高于环境压力时，气体离开喷口后仍会继续膨胀。膨胀波与压缩波交替作用，形成具有重复结构的射流区域；在一定压比下还可能出现较强的中心激波。推进、泄放和高速喷吹设备都需要关注这种外部膨胀过程。

本例采用 Ladenburg 喷流的公开基准，直接在喷口出口给定静压、静温和速度，由 rhoCentralFoam 求解下游可压缩射流。随包初始场为公开的发展场，适合先检查边界与结果结构，再进行网格或压比研究。

几何、尺寸与基准工况

采用轴对称楔形区域，计算长度 30 mm、外半径 10 mm，喷口半径 5 mm。喷口边界为 inlet，外围环境与下游出口分别设置。网格包含 60 个轴向单元和共 20 个径向单元，完整坐标由毫米尺度字典转换到米。

模型与配置来源：OpenFOAM v2512 · compressible/rhoCentralFoam/LadenburgJet60psi。

参数 基准值 设置位置与作用
喷口速度 315.6 m/s 0.orig/U.gz/inlet
喷口静压、静温 271724 Pa、247.1 K 0.orig/p.gz、T.gz
环境压力、温度 101325 Pa、297 K 外围边界
喷口直径 10 mm system/blockMeshDict
气体模型 理想空气，Cp = 1004.5 J/(kg·K) constant/thermophysicalProperties

求解方法与物理模型

欠膨胀程度首先由喷口静压与环境压力之比 pe/p∞p_e/p_\inftype​/p∞​ 描述。气流在膨胀中将焓转化为动能，满足总焓关系 h0=h+U2/2h_0=h+U^2/2h0​=h+U2/2。局部马赫数 Ma=U/γRTMa=U/\sqrt{\gamma RT}Ma=U/γRT​ 随压力和温度变化，激波区域则出现动能向内能的不可逆转化。

本例使用 rhoCentralFoam。网格与边界定义在 constant 和初始场目录，离散格式和方程求解设置分别位于 system/fvSchemes、system/fvSolution；多区域模型在相应区域子目录中保存这些文件。

获取文件与准备网格

下载完整算例包。包内包含模型资源、初始场、物性、数值设置、运行脚本和来源记录。

先在 Linux 终端加载 OpenCFD OpenFOAM v2512。采用标准软件包安装路径时执行下列命令；安装在其他目录时，将路径改为该安装目录下的 etc/bashrc。

Bash / 终端2 行
source /usr/lib/openfoam/openfoam2512/etc/bashrc
echo "$WM_PROJECT_VERSION"

输出应为 v2512。随后进入下载目录，解压并生成网格：

Bash / 终端3 行
unzip ladenburg-jet.zip
cd ladenburg-jet
bash Allmesh

Allmesh 按下表顺序生成网格并执行 checkMesh，每一步的输出保存在相应 log.* 文件中。脚本在命令失败或网格检查不通过时停止。

网格步骤 作用
复制初始场 把 0.orig 中的初始场复制到 0 目录。
blockMesh 按顶点、块结构和加密比例生成背景网格。

首次生成网格前，在 0.orig/ 修改初始场与边界；Allmesh 会把它们复制到 0/。网格生成后继续调整边界，应修改 0/ 中的对应文件。 修改几何或网格字典时，在新目录重新解压并生成网格；保留已有结果目录，便于对比前后工况。

关键配置与解读

1. 0.orig/p.gz

foam5 行
inlet
{
    type            fixedValue;
    value           uniform 271724;
}

入口代表喷口出口截面，因此这里填的是该截面的静压。不能把上游气罐总压直接写入同一固定静压边界，并仍保留原来的速度和温度。

查看该配置的官方原文件；本算例采用的完整文件保存在下载包的同一路径。

2. 0.orig/T.gz

foam5 行
inlet
{
    type            fixedValue;
    value           uniform 247.1;
}

247.1 K 是喷口静温，低于环境温度，反映上游加速膨胀。与速度共同计算总焓，可检查这组入口是否对应一致的气体状态。

查看该配置的官方原文件；本算例采用的完整文件保存在下载包的同一路径。

求解运行与检查

Bash / 终端2 行
bash Allsolve
tail -n 40 log.rhoCentralFoam

Allsolve 读取生成的网格和初始场，调用 rhoCentralFoam；日志用于观察残差、连续性误差及本模型的迭代信息。时间控制给出计算起止位置和输出频率。

控制项 配置值
startFrom latestTime
startTime 0
endTime 2e-05
deltaT 1e-10
writeControl adjustable
writeInterval 2e-05
adjustTimeStep yes
maxCo 0.5

先确认网格检查通过、入口出口或封闭域的质量收支合理，再观察关键工程量是否稳定。稳态问题同时比较残差与出口量；周期或波动问题保留一段连续结果，用多个周期的统计量比较工况。

结果提取与工程分析

在 ParaView 中打开 case.foam，勾选喷口与外部空间，点击 Apply。先选择最后一个已写出的时刻，以 p 着色；用 Rescale to Data Range 更新色标。使用 Slice 查看内部截面，使用 Plot Over Line 沿关注方向提取曲线，最后通过 Save Data 导出表格。对比不同工况时固定截面位置和色标范围。

沿中心线绘制压力、密度、温度和马赫数，将压力振荡与激波胞位置对应。用密度梯度显示压缩与膨胀结构，检查外围边界是否出现明显的反射波。

开展入口压比研究时，从一致的总温、总压或出口状态重新确定三项入口量。增加轴向与径向网格分辨率，比较主要压力峰位置，而不是只比较渲染图的清晰程度。

熊猫说： 案例名称中的 60 psi 是原始工况标识，求解器边界采用的是已经换算的 SI 静态量。配置时以文件中的 Pa、K 和 m/s 为准。
