# FoamLab

面向中文读者的 OpenFOAM 学习网站，将系统课程、配置速查、算例练习与学习交流放在一起。

**访问网站：[foamlabshark.github.io](https://foamlabshark.github.io/)**

## 在这里学习什么

- **系统课程**：从安装与第一个算例开始，逐步学习网格、边界条件、数值方法、湍流、多相流、传热与后处理。
- **速查手册**：查找常用命令、字典参数和功能对象，结合配置示例理解用法。
- **算例实践**：通过网格检查、求解设置和结果分析，把课程内容用于具体问题。
- **学习交流**：记录学习进度，发表评论与回复，交流算例中的问题。
- **熊猫小镇**：在学习之余探索小镇、完成挑战、收集卡片，与其他学习者相遇。

## 如何开始

初次接触 OpenFOAM，可以从网站的课程目录按顺序学习；遇到具体配置问题，可以使用站内搜索或速查手册。

运行示例时，请留意课程标注的 OpenFOAM 发行分支与版本，结合自己的计算环境调整配置。

## 关于本仓库

本仓库用于发布 FoamLab 网站，主要包含构建后的网页、样式、浏览器脚本和公开学习资源，由 GitHub Pages 提供网页访问。

完整开发源码在独立的私有仓库维护。日常阅读、学习和使用网站，请直接访问上方链接。
