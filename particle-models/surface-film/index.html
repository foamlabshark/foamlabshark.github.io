表面液膜与液滴交换

正在打开最新内容…

在壁面上求解薄液膜的质量、动量和能量，并可与液滴沉积、飞溅和蒸发交换。

简要介绍

壁面液层较薄时，可沿厚度积分，把液体描述为壁面上的膜厚、平均速度和温度。液滴碰壁、蒸发和液膜释放又使液膜与主流交换质量和能量。

表面液膜模型在壁面区域描述薄液膜流动，并可与主流及颗粒云交换质量、动量和热量。液膜区域与主流区域之间的映射负责传递这些信息。

先建立液膜网格和区域对应关系，再设置厚度初值、物性、相变及释放模型。运行后应分别检查液膜存量和区域间交换量。

设置位置与参数

算例问题：flameSpreadWaterSuppressionPanel

可燃板表面发生火焰蔓延，同时施加水喷淋以吸收热量并影响火焰发展。算例连接固体热解、气相燃烧、液滴与表面液膜，需按相互作用关系理解各个子模型。

算例出处：OpenCFD OpenFOAM v2512 官方教程 combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel。

本页重点配置：combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel/constant/surfaceFilmProperties。下表说明各条目的作用。完整算例的网格、初始场和配套模型见后文。

条目含义与设置
surfaceFilmModel选择液膜求解模型。
region液膜所属区域及其与主网格的对应关系。
injectionModels液膜向颗粒云的释放模型。
phaseChangeModel液膜蒸发或凝结模型。

官方配置示例

constant/surfaceFilmProperties

本算例的配套配置，字段和参数见文件正文。

配置出处：OpenCFD OpenFOAM v2512 官方教程 combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel/constant/surfaceFilmProperties（原文件）。

foam79 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      surfaceFilmProperties;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

active          true;

surfaceFilmModel thermoSingleLayer;

region          filmRegion;

thermoSingleLayerCoeffs
{
    filmThermoModel liquid;
    liquidCoeffs
    {
        useReferenceValues  no;
        liquid          H2O;
    }
    filmViscosityModel  liquid;

    hydrophilic     no;
    deltaWet        1e-4;

    turbulence      laminar;
    laminarCoeffs
    {
        Cf              0.005;
    }

    radiationModel  none;
    standardRadiationCoeffs
    {
        beta     0.75;
        kappaBar 0.25;
    }

    upperSurfaceModels
    {
        heatTransferModel constant;
        constantCoeffs
        {
           c0              10;
        }
    }

    lowerSurfaceModels
    {
        heatTransferModel constant;
        constantCoeffs
        {
            c0             100;
        }
    }

    injectionModels
    ();

    forces
    (
        thermocapillary
    );

    phaseChangeModel standardPhaseChange;

    standardPhaseChangeCoeffs
    {
        Tb              373;
        deltaMin        1e-8;
        L               1.0;
    }
}


// ************************************************************************* //

surfaceFilmModel=thermoSingleLayer 选择液膜模型。当前文件关闭液膜计算，因而不建立有质量和能量输运的活动液膜；启用实际模型时还须建立对应 region 的网格、字段和耦合边界。

0.orig/C3H8：初始场及其边界条件；量纲见 dimensions，场名见 object。

0.orig/C3H8

配置出处：OpenCFD OpenFOAM v2512 官方教程 combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel/0.orig/C3H8（原文件）。

foam50 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       volScalarField;
    object      C3H8;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

dimensions      [0 0 0 0 0 0 0];

internalField   uniform 0;

boundaryField
{
    outlet
    {
        type            inletOutlet;
        inletValue      $internalField;
        value           $internalField;
    }

    ground
    {
        type            zeroGradient;
    }

    side
    {
        type            inletOutlet;
        inletValue      $internalField;
        value           $internalField;
    }

    inlet
    {
        type                totalFlowRateAdvectiveDiffusive;
        value               uniform 1;
    }

    region0_to_pyrolysisRegion_coupledWall
    {
        type                totalFlowRateAdvectiveDiffusive;
        massFluxFraction    1.0;
        value               $internalField;
    }
}


// ************************************************************************* //

0.orig/C3H8 设置 C3H8 的内部初值和边界条件。dimensions 为 [0 0 0 0 0 0 0]，为无量纲量。internalField 为 uniform 0；uniform 表示所有内部单元采用相同初值。

  • outlet、side 采用 inletOutlet，出流时外推，回流时采用 inletValue。参数为 inletValue $internalField，value $internalField。
  • ground 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。
  • inlet 采用 totalFlowRateAdvectiveDiffusive。参数为 value uniform 1。
  • region0_to_pyrolysisRegion_coupledWall 采用 totalFlowRateAdvectiveDiffusive。参数为 massFluxFraction 1.0，value $internalField。

system/filmRegion/fvSolution

配置出处：OpenCFD OpenFOAM v2512 官方教程 combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel/system/filmRegion/fvSolution（原文件）。

foam50 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      fvSolution;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

solvers
{
    hf
    {
        solver          PBiCGStab;
        preconditioner  DILU;
        tolerance       0;
        relTol          1e-3;
    }

    "(Uf|deltaf\*rhof)"
    {
        solver          PBiCGStab;
        preconditioner  DILU;
        tolerance       1e-10;
        relTol          0;
    }

    deltaf
    {
        solver          PBiCGStab;
        preconditioner  DILU;
        tolerance       1e-10;
        relTol          0;
    }
}

PISO
{
    momentumPredictor yes;
    nOuterCorr      1;
    nCorr           1;
    nNonOrthCorr    0;
    dfMin           1e-10;
}

relaxationFactors
{}


// ************************************************************************* //

system/filmRegion/fvSolution分别控制单个线性方程的求解和各物理场之间的耦合。带引号的字段名可使用正则表达式，一组设置因而可以覆盖多个字段。

system/filmRegion/fvSolution 的线性求解设置
字段或匹配规则本例设置的作用
hfsolver PBiCGStab：线性方程采用 PBiCGStab 方法；preconditioner DILU：选择线性方程的预条件方法；tolerance 0：线性方程绝对残差阈值；relTol 1e-3：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
"(Uf|deltaf\*rhof)"solver PBiCGStab：线性方程采用 PBiCGStab 方法；preconditioner DILU：选择线性方程的预条件方法；tolerance 1e-10：线性方程绝对残差阈值；relTol 0：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
deltafsolver PBiCGStab：线性方程采用 PBiCGStab 方法；preconditioner DILU：选择线性方程的预条件方法；tolerance 1e-10：线性方程绝对残差阈值；relTol 0：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
  • PISO/momentumPredictor = yes：控制是否单独求解动量预测步骤。

复制与运行完整算例

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel" "$FOAM_RUN/flameSpreadWaterSuppressionPanel-reference"
cd "$FOAM_RUN/flameSpreadWaterSuppressionPanel-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

Allrun：官方预处理、求解和后处理执行顺序。

Allrun

配置出处：OpenCFD OpenFOAM v2512 官方教程 combustion/fireFoam/LES/flameSpreadWaterSuppressionPanel/Allrun（原文件）。

Bash / 终端36 行
#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

restore0Dir

# create the underlying block mesh
runApplication blockMesh

# create faceSet for burner inlet and faceZone for coupled wall
runApplication topoSet

# create burner inlet
runApplication createPatch -overwrite

# extrude Film
runApplication extrudeToRegionMesh -dict system/extrudeToRegionMeshDictFilm -overwrite

# extrude pyrolysis
runApplication -s pyr extrudeToRegionMesh -dict system/extrudeToRegionMeshDictPyr -overwrite

# change samplePatch in the boundary to coupled patch betwee region0 and
# pyrolysis
runApplication changeDictionary -region filmRegion -constant

# create faceSets for inlet, outlet, sides for the Film
runApplication -s filmRegion topoSet -region filmRegion

# create actual patches
runApplication -s filmRegion createPatch -region filmRegion -overwrite

# Run
runApplication $(getApplication)

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. restore0Dir 将 0.orig 恢复为求解所用的 0 目录。
  3. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格。
  4. topoSet 按几何、网格属性和集合关系创建或修改 sets/zones。
  5. createPatch 把已有边界面或 faceSet 重组为指定 patch。结果覆盖当前网格。
  6. extrudeToRegionMesh 将选定面集挤出为独立网格区域，用于薄层、液膜等模型。结果覆盖当前网格。
  7. changeDictionary 按替换字典批量修改场文件或网格字典条目。处理区域由 filmRegion 指定。
  8. topoSet 按几何、网格属性和集合关系创建或修改 sets/zones。处理区域由 filmRegion 指定。
  9. createPatch 把已有边界面或 faceSet 重组为指定 patch。处理区域由 filmRegion 指定。结果覆盖当前网格。
  10. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
