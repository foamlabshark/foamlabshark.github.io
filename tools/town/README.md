# 熊猫小镇维护

入口为 `/town/`；使用网站现有 GitHub 登录和熊猫经验账本。界面采用像素素材、SVG 地表和 DOM 角色，实时同步在线状态和动作，街道上的走动在各自设备中播放。

方向键或 WASD 移动，空格或 E 与附近建筑互动，也可以点击目的地行走。手机提供方向键和 A 键。右上角可切换小镇、查看建筑目录、设置昼夜光照；光照默认随设备当地时间变化。美术图集、比例和分层见 [ART.md](ART.md)。

## 管理位置

网站管理 → 熊猫小镇：

- **举报处理**：查看理由、隐藏或恢复留言、标记处理完成。
- **居民留言**：按内容或作者搜索，筛选状态，按时间排序。
- **小镇居民**：查看自愿公开的省份、团队名称、入住和最近到访时间，打开小屋。
- **研究所名称**：维护统一名称和别名；同省至少三位成员时显示建筑。
- **开放与活动**：关闭、仅管理员测试或全部开放；调整互动开关、搬家间隔、留言上限、单屏人数及节日领取日期。

社区管理员可处理留言与举报；网站管理员还可调整开放设置和名称合并规则。所有列表保留筛选、排序和首末页导航。六篇景点文章可以在普通内容管理中搜索“熊猫小镇”，分别编辑标题、正文和位置。

- `themes/foam-lab/source/assets/town/`：场景、街道、账号入口、管理界面与熊猫扩展。
- `tools/town/build-data.py`：省份布局和 61 项新增收藏；与原有 42 项合并为 103 项。
- `tools/town/build-landmarks.py`：六篇景点介绍和首次上线种子 SQL。`seed.sql` 使用冲突跳过，保留后台已有修改。

- `tools/town/build-migration.py`：组合 SQL 文件，输出已由 CLI 建立的迁移文件。
- `supabase/tests/panda-town.sql`：可回滚的数据库行为与权限测试。
- `tools/check-town.cjs`：浏览器操作测试；使用隔离数据，不公开发帖。
- `tools/check-town-game.cjs`：移动、碰撞、地图布局、像素行走、昼夜路灯和手机操作测试。
- `tools/check-town-controls.cjs`：WASD、方向键、中文输入法、松键、弹窗暂停和手机触控测试。
- `tools/check-town-layout.cjs`：满员街道、研究所扩展、建筑与道路间距、路灯占地，以及导航顶部入口。

## 规则与隐私

入住公开名称、等级、外观、所选省份，以及自行填写的学校或团队。不会读取 IP 位置；原有个人资料中的单位和学习历史也不会自动公开。小于三名居民的省份隐藏地图人数统计。留言为公开文字，关闭留言板后只对主人显示。合影须双方确认，一方收起照片只影响自己的照片墙。

采纳回答奖励与回复奖励分别记录，取消采纳只撤回采纳奖励。奖励不重复累计；删除或隐藏回答会按原有社区规则撤回对应奖励。送竹子每日每人对同一居民一次，接收经验每日最多五次。景点奖励按六种景点分别计算，每种一次。

搬家默认七天，留言默认每小时十条，快捷动作默认六个。重复退出、入住仍遵守搬家间隔。照片邀请有效六十秒，双人动作邀请有效十五秒。后台的敏感词表默认为空，可按社区需要维护。

节日按北京时间判断。2026 年初始配置包含国庆 10 月 1–7 日，其余日期由管理员按年度添加。已经领取的节日收藏永久保留。

## 发布与回退

前端发布到既有 GitHub Pages；数据库迁移先保持 `town_enabled = "off"`，完成页面和权限检查后再切换为 `on`。日常临时维护只需要关闭入口，无需删除数据。

`rollback/pet_api.sql` 保留迁移前的熊猫接口。`build-rollback.py` 生成紧急回退脚本 **但不执行**。紧急回退会删除小镇居民、留言、竹子、合影和举报数据，应先备份数据库及导出数据，再连同旧版前端恢复。正常更新无需使用该脚本。

后续可另行扩展实时位置同步；本版没有共享位置广播，也不提供街道自由文本聊天。
