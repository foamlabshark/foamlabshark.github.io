Usage: foamCopySettings srcDir dstDir

    Copy OpenFOAM settings from one case to another, without copying
    the mesh or results.
    - requires rsync

Note
    The foamCopySettings.rc (found via foamEtcFile) can be used to add any
    custom rsync options.
