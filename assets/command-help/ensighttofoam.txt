OpenFOAM v2512 command reference
Command: ensightToFoam
Evidence: help-verified
Source: https://gitlab.com/openfoam/core/openfoam/-/blob/OpenFOAM-v2512/applications/utilities/mesh/conversion/ensightToFoam/ensightMeshReader.C


Usage: ensightToFoam [OPTIONS] <.geo file>
Arguments:
  <.geo file>       The file containing the geometry
Options:
  -case <dir>       Case directory (instead of current directory)
  -debug-switch <name=val>
                    Set named DebugSwitch (default value: 1).
                    [Can be used multiple times]
  -fileHandler <handler>
                    Override the file handler type
  -info-switch <name=val>
                    Set named InfoSwitch (default value: 1).
                    [Can be used multiple times]
  -keepHandedness   Do not automatically flip inverted cells (default is to do
                    a geometric test)
  -lib <name>       Additional library or library list to load.
                    [Can be used multiple times]
  -mergeTol <factor>
                    Merge tolerance as a fraction of bounding box - 0 to
                    disable merging
  -no-libs          Disable use of the controlDict 'libs' entry
  -noFunctionObjects
                    Do not execute function objects
  -opt-switch <name=val>
                    Set named OptimisationSwitch (default value: 1).
                    [Can be used multiple times]
  -scale <factor>   Geometry scaling factor - default is 1
  -doc              Display documentation in browser
  -doc-source       Display source code in browser
  -help             Display short help and exit
  -help-man         Display full help (manpage format) and exit
  -help-notes       Display help notes (description) and exit
  -help-full        Display full help and exit
