OpenFOAM v2512

P1

正在打开最新内容…

用辐射传递方程的低阶角度近似求解入射辐射，适合光学较厚、方向性较弱的介质。

简要介绍

P1 将辐射输运近似为入射辐射 G 的扩散方程，并将辐射热源加入能量方程。它适用于吸收或散射较强、方向性不是主要特征的辐射问题。

配置包括 radiationProperties、G 的初值和壁面条件，以及参与耦合的温度场。介质吸收系数和壁面发射率分别控制体积内的辐射交换与表面交换。

P1 将方向相关的辐射输运近似为入射辐射 G 的扩散方程。v2512 使用：

∇⋅(Γ∇G)−aG=−4eσSBT4−E,Γ=13a+σeff\nabla\cdot(\Gamma\nabla G)-aG=-4e\sigma_{\rm SB}T^4-E,\qquad\Gamma=\frac1{3a+\sigma_{\rm eff}}∇⋅(Γ∇G)−aG=−4eσSB​T4−E,Γ=3a+σeff​1​

a 为吸收系数，e 为发射系数，σeff\sigma_{\rm eff}σeff​ 为散射模型返回的有效系数，E 为附加体积发射项；程序另加极小量避免分母为零。G 的单位为 W/m²，壁面辐射通量按 qr=−Γ∂G∂nq_r=-\Gamma\frac{\partial G}{\partial n}qr​=−Γ∂n∂G​ 计算。只有忽略散射时，Γ 才近似为 1/(3a)1/(3a)1/(3a)。P1 更适于辐射方向性不强、光学厚度较大的介质。

设置位置与参数

算例问题：hotRadiationRoom

室内热源加热空气和周围壁面，浮力对流与表面、介质辐射共同传递能量。算例需要同时配置温度、流动和辐射边界，可比较房间温度、循环流动及壁面辐射热流。

算例出处：OpenCFD OpenFOAM v2512 官方教程 heatTransfer/buoyantSimpleFoam/hotRadiationRoom。

本页重点配置：heatTransfer/buoyantSimpleFoam/hotRadiationRoom/constant/radiationProperties。下表说明各条目的作用。完整算例的网格、初始场和配套模型见后文。

条目含义与设置
radiationModel选择 P1。
absorptionEmissionModel定义介质的吸收、发射及体积辐射源。
scatterModel定义散射；none 表示不考虑散射。
solverFreq辐射方程的求解间隔。

官方配置示例

constant/radiationProperties

辐射求解方法及介质辐射物性。

配置出处：OpenCFD OpenFOAM v2512 官方教程 heatTransfer/buoyantSimpleFoam/hotRadiationRoom/constant/radiationProperties（原文件）。

foam31 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      radiationProperties;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

radiation on;

radiationModel  P1;

// Number of flow iterations per radiation iteration
solverFreq 1;

absorptionEmissionModel constantAbsorptionEmission;

constantAbsorptionEmissionCoeffs
{
    absorptivity    absorptivity    [0 -1 0 0 0 0 0] 0.5;
    emissivity      emissivity      [0 -1 0 0 0 0 0] 0.5;
    E               E               [1 -1 -3 0 0 0 0] 0;
}

scatterModel    none;

sootModel       none;


// ************************************************************************* //

constant/radiationProperties 中各项设置的作用如下。

  • radiationModel 设为 P1：选择辐射传递模型。
  • solverFreq 设为 1：辐射方程的求解间隔。
  • absorptionEmissionModel 设为 constantAbsorptionEmission：定义介质的吸收、发射及体积辐射源。
  • scatterModel 设为 none：定义散射；none 表示不考虑散射。

  • floor、ceiling 采用 fixedValue，边界始终采用给定的 value。参数为 value uniform 300.0。
  • fixedWalls 采用 zeroGradient，沿外法向采用零梯度，边界值由内部场外推。
  • box 采用 fixedValue，边界始终采用给定的 value。参数为 value uniform 500.0。

system/fvSolution：线性求解器、耦合循环、容差与松弛。

system/fvSolution

配置出处：OpenCFD OpenFOAM v2512 官方教程 heatTransfer/buoyantSimpleFoam/hotRadiationRoom/system/fvSolution（原文件）。

foam71 行
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    object      fvSolution;
}
// * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * //

solvers
{
    p_rgh
    {
        solver          PCG;
        preconditioner  DIC;
        tolerance       1e-06;
        relTol          0.01;
    }

    "(U|h|k|epsilon)"
    {
        solver          PBiCGStab;
        preconditioner  DILU;
        tolerance       1e-05;
        relTol          0.1;
    }

    G
    {
        $p_rgh;
        tolerance       1e-05;
        relTol          0.1;
    }
}

SIMPLE
{
    nNonOrthogonalCorrectors 0;
    pRefCell        0;
    pRefValue       0;

    residualControl
    {
        p_rgh           1e-2;
        U               1e-3;
        h               1e-3;
        G               1e-3;

        // possibly check turbulence fields
        "(k|epsilon|omega)" 1e-3;
    }
}

relaxationFactors
{
    fields
    {
        rho             1.0;
        p_rgh           0.7;
    }
    equations
    {
        U               0.2;
        h               0.2;
        "(k|epsilon|R)" 0.5;
        G               0.7;
    }
}


// ************************************************************************* //

system/fvSolution分别控制单个线性方程的求解和各物理场之间的耦合。带引号的字段名可使用正则表达式，一组设置因而可以覆盖多个字段。

system/fvSolution 的线性求解设置
字段或匹配规则本例设置的作用
p_rghsolver PCG：线性方程采用 PCG 方法；preconditioner DIC：选择线性方程的预条件方法；tolerance 1e-06：线性方程绝对残差阈值；relTol 0.01：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
"(U|h|k|epsilon)"solver PBiCGStab：线性方程采用 PBiCGStab 方法；preconditioner DILU：选择线性方程的预条件方法；tolerance 1e-05：线性方程绝对残差阈值；relTol 0.1：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
Gtolerance 1e-05：线性方程绝对残差阈值；relTol 0.1：相对初始残差的降低比例；0 表示仅按绝对阈值判断。
  • SIMPLE/nNonOrthogonalCorrectors = 0：压力或扩散方程的非正交校正次数。
  • SIMPLE/pRefCell = 0：设置压力参考单元。
  • SIMPLE/pRefValue = 0：设置该单元的压力参考值。
  • SIMPLE/residualControl/p_rgh = 1e-2：用于判断外层耦合或稳态迭代是否达到残差要求。
  • SIMPLE/residualControl/U = 1e-3：用于判断外层耦合或稳态迭代是否达到残差要求。
  • SIMPLE/residualControl/h = 1e-3：用于判断外层耦合或稳态迭代是否达到残差要求。
  • SIMPLE/residualControl/G = 1e-3：用于判断外层耦合或稳态迭代是否达到残差要求。
  • SIMPLE/residualControl/"(k|epsilon|omega)" = 1e-3：用于判断外层耦合或稳态迭代是否达到残差要求。
  • relaxationFactors/fields/rho = 1.0：限制每轮迭代的更新幅度；越接近 1，松弛越弱。

复制与运行完整算例

加载 OpenFOAM v2512 环境后，将完整教程复制到新的工作目录。以下命令调用官方脚本，按算例顺序建立网格、初始化并求解。

Bash / 终端4 行
mkdir -p "$FOAM_RUN"
cp -r "$FOAM_TUTORIALS/heatTransfer/buoyantSimpleFoam/hotRadiationRoom" "$FOAM_RUN/hotRadiationRoom-reference"
cd "$FOAM_RUN/hotRadiationRoom-reference"
./Allrun

命令依次创建工作目录、复制教程并进入副本；./Allrun 执行该副本中的计算流程。

Allrun：官方预处理、求解和后处理执行顺序。

Allrun

配置出处：OpenCFD OpenFOAM v2512 官方教程 heatTransfer/buoyantSimpleFoam/hotRadiationRoom/Allrun（原文件）。

Bash / 终端12 行
#!/bin/sh
cd "${0%/*}" || exit                                # Run from this directory
. ${WM_PROJECT_DIR:?}/bin/tools/RunFunctions        # Tutorial run functions
#------------------------------------------------------------------------------

restore0Dir

runApplication blockMesh

runApplication $(getApplication)

#------------------------------------------------------------------------------
  1. cd 切换当前工作目录。
  2. restore0Dir 将 0.orig 恢复为求解所用的 0 目录。
  3. blockMesh 读取 blockMeshDict，生成由六面体块组成的网格。
  4. 从 system/controlDict 的 application 读取求解器名称，运行后将日志保存在算例目录。
