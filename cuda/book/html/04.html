第 4 章 文档结构

本章按原文组织章节清单，添加了便于阅读的目录小标题。

全书章节安排

本文档由以下部分组成：

  • 引言（Introduction）： 对 CUDA 作总体介绍。
  • 编程模型（Programming Model）： 概述 CUDA 编程模型。
  • 编程接口（Programming Interface）： 介绍编程接口。
  • 硬件实现（Hardware Implementation）： 说明硬件实现方式。
  • 性能指南（Performance Guidelines）： 提供提升性能的建议。
  • 支持 CUDA 的 GPU（CUDA-Enabled GPUs）： 列出支持 CUDA 的设备。
  • C++ 语言扩展（C++ Language Extensions）： 详细介绍对 C++ 语言所作的扩展。
  • 协作组（Cooperative Groups）： 介绍用于不同 CUDA 线程组的同步原语。
  • CUDA 动态并行（CUDA Dynamic Parallelism）： 介绍如何从一个内核中启动并同步另一个内核。
  • 虚拟内存管理（Virtual Memory Management）： 介绍如何管理统一虚拟地址空间。
  • 流有序内存分配器（Stream Ordered Memory Allocator）： 介绍如何按执行流顺序进行内存分配与释放。
  • 图内存节点（Graph Memory Nodes）： 介绍 CUDA 图如何创建并拥有内存分配。
  • 数学函数（Mathematical Functions）： 列出 CUDA 支持的数学函数。
  • C++ 语言支持（C++ Language Support）： 列出设备代码支持的 C++ 语言特性。
  • 纹理读取（Texture Fetching）： 进一步说明纹理读取。
  • 计算能力（Compute Capabilities）： 给出不同设备的技术规格和更多架构细节。
  • 驱动程序 API（Driver API）： 介绍底层驱动程序 API。
  • CUDA 环境变量（CUDA Environment Variables）： 列出 CUDA 环境变量。
  • 统一内存编程（Unified Memory Programming）： 介绍统一内存编程模型。
