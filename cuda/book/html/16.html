第十六章 数学函数（Mathematical Functions）

对应原 PDF 第 411–424 页（原书印刷页码 395–408）。本章是参考资料，重点保留函数名、误差范围、适用条件和表格数值。ULP 表示“最后一位的单位”（Unit in the Last Place）。

设备代码中支持的数学函数包括 C/C++ 标准库中的部分数学函数，以及仅能在设备代码中使用的内建函数。本章在适用时给出这些函数的精度信息，并使用 ULP 量化误差。关于 ULP 的定义，可参阅 Jean-Michel Muller 的论文 On the definition of ulp(x)，RR-5504，LIP RR-2005-09，INRIA，LIP，2005，第 16 页。

设备代码中的数学函数不会设置全局 errno 变量，也不会通过浮点异常报告错误。因此，如果应用程序需要错误诊断机制，用户应自行检查函数的输入和输出。用户也有责任确保指针参数有效。不得向数学函数传入未初始化参数，否则可能导致未定义行为；这些函数会内联到用户程序中，因此也会受到编译器优化的影响。

16.1 标准函数（Standard Functions）

本节中的函数可用于主机代码和设备代码。本节给出每个函数在设备端执行时的误差范围；如果主机系统没有提供相应函数，也会给出主机端执行时的误差范围。

这些误差范围基于大量但并非穷尽的测试，因此并不构成有保证的误差上限。

单精度浮点函数（Single-Precision Floating-Point Functions）

加法和乘法符合 IEEE 标准，因此最大误差为 0.5 ULP。

将单精度浮点操作数舍入为整数、且结果仍为单精度浮点数时，推荐使用 rintf() 而不是 roundf()。原因是设备端的 roundf() 会映射为 4 条指令，而 rintf() 只映射为一条指令。truncf()、ceilf() 和 floorf() 也各自只映射为一条指令。

16.2 内建函数（Intrinsic Functions）

本节中的函数只能用于设备代码。

其中包括一些精度较低但速度更快的标准函数版本。它们通常在原函数名前加双下划线，例如 __sinf(x)。这些函数映射到更少的原生指令，因此执行速度更快。

单精度浮点函数（Single-Precision Floating-Point Functions）

__fadd_[rn,rz,ru,rd]() 和 __fmul_[rn,rz,ru,rd]() 分别映射为加法和乘法操作，编译器绝不会将它们合并为 FMAD 指令。相比之下，由 * 和 + 运算符生成的加法与乘法，经常会被合并为 FMAD 指令。

函数名带有以下后缀时，表示使用相应的舍入模式：

  • _rn：舍入到最近值，遇中间值舍入到偶数；
  • _rz：向零舍入；
  • _ru：向上舍入，即朝正无穷方向；
  • _rd：向下舍入，即朝负无穷方向。

浮点除法的精度取决于代码使用 -prec-div=false 还是 -prec-div=true 编译。使用 -prec-div=false 时，普通除法运算符 / 与 __fdividef(x, y) 的精度相同；但当 \(2^{126} < |y| < 2^{128}\) 时，__fdividef(x, y) 返回 0，而 / 运算符仍会返回符合表 19 所述精度的结果。

此外，当 \(2^{126} < |y| < 2^{128}\) 且 x 为无穷大时，__fdividef(x, y) 会因计算中出现“无穷大乘以零”而返回 NaN；而 / 运算符会返回无穷大。

另一方面，如果使用 -prec-div=true 编译，或者完全不指定 -prec-div 选项（默认值为 true），则 / 运算符符合 IEEE 标准。

__tanf(x) 根据其实现 __sinf(x) * (1 / __cosf(x)) 推导
__powf(x, y) 根据其实现 exp2f(y * __log2f(x)) 推导
__tanhf(x) 当前实现的最大相对误差为 \(2^{-11}\)。即使编译器设置 -ftz=true，该快速内建函数的次正规结果也不会被刷新为零。仅适用于计算能力至少为 7.5 的设备；其他设备默认使用常规 tanhf() 的行为

双精度浮点函数（Double-Precision Floating-Point Functions）

__dadd_rn() 和 __dmul_rn() 分别映射为加法和乘法操作，编译器绝不会将它们合并为 FMAD 指令。相比之下，由 * 和 + 运算符生成的加法与乘法，经常会被合并为 FMAD 指令。

本章术语与阅读提示

  • ULP（Unit in the Last Place）： 最后一位的单位，是衡量浮点计算结果与正确舍入结果之间差异的常用方式。
  • 最大 ULP 误差： 表示测试范围内的最大误差；标准函数表中的数值基于大量但非穷尽的测试，并非对所有输入都作出形式化保证。
  • -use_fast_math： 会让表 18 中的部分标准数学函数转为更快的内建函数；使用前应确认应用能接受相应的精度和特殊值处理差异。
  • 舍入后缀： _rn、_rz、_ru 和 _rd 分别表示舍入到最近偶数、向零、向正无穷和向负无穷。
