surfaces

在截面、等值面或指定表面上采样。

简要介绍

surfaces 在平面、等值面或指定表面上提取体场，适合观察速度截面、温度分布和水气界面。几何定义决定采样位置，字段列表决定提取内容，结果可按 VTK 等格式保存。

配置方法

将下面的对象放入 system/controlDict 的 functions 字典。对象名可以自定；type 选择工具，libs 加载实现它的库。

示例算例：溃坝两相流。

完整的配置放置与运行方法见 functionObject 配置说明。

平面定义

外层 type 必须为 surfaces。cuttingPlane、patch、isoSurface 等类型写在 surfaces 子字典中各个采样面的 type。fields 是要输出的场；isoField 是用来定位等值面的标量场，两者用途不同。一个对象中可以并列定义多张不同类型的表面。

默认平面用 point 和 normal 定义。设置 planeType pointAndNormal 时，将二者写入 pointAndNormalDict。planeEquation 在 planeEquationDict 中填写 a、b、c、d；embeddedPoints 在 embeddedPointsDict 中填写三个不共线的点 point1、point2、point3。normal 使用非零向量，offsets 与网格坐标采用相同单位。

搜索几何的参数

distanceSurface、surfaceCut 和 patchEdge 的 surfaceType 使用 searchableSurface 类型。几何参数与 surfaceType 同级；它与外层采样面的 type 属于不同注册表。

参数说明
triSurfaceMeshsurfaceName 指定 constant/triSurface 中的表面文件。表面坐标与网格采用相同单位。
searchableSpherecentre 和 radius 定义球面。
searchableCylinderpoint1、point2 和 radius 定义有限圆柱。
searchableBoxmin、max 定义轴对齐包围盒的两个对角点。
searchablePlane使用 point、normal，或 planeType 对应的平面定义子字典；与本页 cuttingPlane 的平面构造规则相同。

配置示例

示例 1 · 基本配置

在指定几何表面上提取场。本例从溃坝的 alpha.water=0.5 等值面提取水气界面，并在该表面采样 U、p_rgh；surfaceFormat vtk 便于用 ParaView 打开。

foam23 行
functions
{
    freeSurface
    {
        type surfaces;
        libs (sampling);

        writeControl writeTime;
        writeInterval 1;
        fields (U p_rgh);
        surfaceFormat vtk;
        surfaces
        {
            waterAir
            {
                type isoSurfaceCell;
                isoField alpha.water;
                isoValue 0.5;
                interpolate true;
            }
        }
    }
}

示例 4 · 切取方腔中间截面

将配置放入 controlDict 的 functions 中。示例方腔范围为 0–0.1 m，厚度 0.01 m，坐标可按网格尺寸调整。interpolate true 在顶点采样，cellPoint 指定插值方案。

foam22 行
functions
{
    midPlane
    {
        type surfaces;
        libs (sampling);
        writeControl writeTime;
        fields (U p);
        surfaceFormat vtk;
        interpolationScheme cellPoint;
        surfaces
        {
            middle
            {
                type cuttingPlane;
                point (0 0 0.005);
                normal (0 0 1);
                interpolate true;
            }
        }
    }
}

示例 5 · 用点和法向显式定义多个平行截面

planeType pointAndNormal 用点和法向定义基准面，point 与 normal 写在 pointAndNormalDict 内。offsets 沿归一化法向偏移，本例的三个截面分别位于 z=0.002z=0.002z=0.002、z=0.005z=0.005z=0.005、z=0.008z=0.008z=0.008 m。

foam27 行
functions
{
    sampleSurfaces
    {
        type surfaces;
        libs (sampling);
        writeControl writeTime;
        fields (U p);
        surfaceFormat vtk;
        interpolationScheme cellPoint;
        surfaces
        {
            parallelCuts
            {
                type cuttingPlane;
                planeType pointAndNormal;
                pointAndNormalDict
                {
                    point (0 0 0.005);
                    normal (0 0 1);
                }
                offsets (-0.003 0 0.003);
                interpolate true;
            }
        }
    }
}

示例 6 · 用平面方程定义截面

planeEquationDict 定义平面方程 ax+by+cz+d=0ax+by+cz+d=0ax+by+cz+d=0；本例的截面位于 z=0.005z=0.005z=0.005 m。

示例 7 · 用三个不共线点定义截面

在 embeddedPointsDict 中填写 point1、point2、point3，定义一个无限平面；输出截面的范围由计算域决定。

示例 8 · 两相界面与壁面一起采样

waterInterface 与 wallData 并列写在 surfaces 中，分别提取水相界面和壁面。isoField 选择用于定位界面的 alpha.water；fields 选择输出量 U、p。使用 p_rgh 的求解器可将 fields 中的 p 改为 p_rgh，patches 填写案例中的壁面名称。

foam29 行
functions
{
    sampleSurfaces
    {
        type surfaces;
        libs (sampling);
        writeControl writeTime;
        fields (U p);
        surfaceFormat vtk;
        interpolationScheme cellPoint;
        surfaces
        {
            waterInterface
            {
                type isoSurface;
                isoField alpha.water;
                isoValue 0.5;
                isoMethod topo;
                interpolate true;
            }
            wallData
            {
                type patch;
                patches (".*Wall");
                interpolate false;
            }
        }
    }
}
